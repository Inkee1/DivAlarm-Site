📌 メニュー概要

"DivLog" — ダイバージェンスアラートのシグナルを受け取る場所です。

"Div" — 「RSI Divergence Complete」または「RSI Divergence Forming」シグナルを設定します。

"EI" — 追加のインジケーターアラートを設定します：価格到達アラート、サポート／レジスタンス接近アラート、EMA/Bollinger Band/Supertrend アラート。（"Extra Indicators"）

"Webhook" — Proユーザーのみ表示されます。強力なアラーム、シグナルの組み合わせ、自動注文のために TradingView webhook を受信します。

"Setting" — アラームの種類、サウンド、紹介報酬の設定、お知らせ、紹介通知を設定します。

📊 シグナル通知の確認（"DivLog"）

"DivLog" は、ダイバージェンスアラートのシグナルを受け取る場所です。

  1. 最大150件のシグナルが保存されます。定期的に整理してください。
  2. 未確認のアラートを表示します。チェックマークを付けるとアラームを解除できます。直近の未確認アラートは最大5件まで表示されます。
  3. 見たいシグナルだけに絞り込めます。

⚙️ RSI ダイバージェンスアラート設定（"Div"）

RSI ダイバージェンスの全体設定

  1. 設定する銘柄を選択します。
  2. 「RSI Divergence Complete」と「RSI Divergence Forming」のどちらのシグナルにするかを選びます。
  3. 一括設定エリア — 下の全項目に設定をまとめて適用します。
  4. +ボタンでダイバージェンスのフィルターを追加します。
  5. フィルターを推奨デフォルト設定にリセットします。
  6. 価格条件を一括で設定します。

個別フィルター設定

  1. 受信する RSI ダイバージェンスシグナルを個別に設定します：

    (a) 希望する時間足を選択します。'RSI Divergence Forming' では、「メイン時間足」と「サブ時間足」の両方を選びます。メイン時間足でダイバージェンスが形成中（価格反転）に、より小さい時間足で RSI のピークが形成されるとアラートが発火します。

    (b) シグナルを選択："Bull(bullish)" または "Bear(bearish)"。青＝アラート有効、グレー＝無効。

    (c) 売られすぎ／買われすぎのしきい値を設定します。'starting RSI' が売られすぎ水準より下なら強気アラート、'starting RSI' が買われすぎ水準より上なら弱気アラート。

    (d) アラームの種類と音を設定します。詳細は設定ページで：

    A 強制アラーム（ループ）— 手動で停止するまで鳴り続け、サイレントモードを無視します

    B 強制アラーム（1回）— 1回だけ鳴り、サイレントモードを無視します

    C 端末設定に従う — 端末の通常のサウンド設定を使用します

    D バイブのみ — 音なしで振動します

    E サイレント — 音も振動もなし

    (e) 有用なシグナルだけに絞るための追加条件を設定します：価格条件、他時間足の RSI 形成条件、ボリンジャーバンド条件。

e0) 条件を複数設定した場合は、関係を設定します："and"（すべて満たす）または "or"（いずれか1つ満たす）。

e1) 価格条件を設定 — ダイバージェンスの開始／終了価格が特定の価格より上／下のときにアラートします。

e2) 別の時間足でダイバージェンスが形成中のときにアラートします。

e3) RSI ダイバージェンスの最終ピーク価格がボリンジャーバンドの外にあるかを確認します。

戦略のヒント

  • 必ず他の指標（レジスタンス、トレンドライン、フィボナッチなど）と組み合わせてください。
  • 他の指標と同様に、RSI ダイバージェンスは100%正確ではありませんが、確率を高めます。
  • 1m、5mのダイバージェンスは見過ごされがちですが、信頼性は 15m < 1h < 4h の順に高まります。 4hのダイバージェンスは信頼性が高いので、A級アラームに設定するのがおすすめです。

📈 追加インジケーターアラート（"EI"）

  1. 設定する銘柄を選択します。
  2. コインの価格アラートを設定します。
  3. EMA（指数移動平均）のクロスアラートを設定します。
  4. サポート／レジスタンスへの接近アラートを設定します。
  5. ボリンジャーバンドのブレイクアウトアラートを設定します。
  6. Supertrendの変化アラートを設定します。

※ 追加インジケーター（3、4、5、6）はログアウトするとリセットされます。

💰 紹介報酬

(a) あなたの紹介コード。このコードで他の人が購読すると、あなたが紹介者として登録されます。

(b) あなたの招待リンク。このリンク経由で購読した人は、自動的にあなたが紹介者として登録されます。

(c) 紹介報酬を受け取るためのウォレットアドレスを入力します。BEP-20 USDT ウォレットである必要があります（主要取引所のウォレット推奨）。入金が正しく行えるかは、DivAlarm のサイトの「My Info」からテストできます。

(d) 紹介報酬の状況（現在の紹介人数、見込み報酬額、確定額、支払済み額）を表示します。

報酬は、紹介されたユーザーの購読支払い（無料トライアルを除く）から14日後に「見込み」から「確定」へ移行します。支払いは毎週火曜日のUTC 0:00に行われます。

紹介報酬の受け取り方

1] 設定 → 紹介報酬 → 報酬受け取り用ウォレットアドレスを入力します。

2] 紹介リンクを共有してください。相手はあなたのコード付きで購読ページに移動します。

3] 相手が購読して支払いが完了すると、報酬が入金されます。
