📌 メニュー概要

「DivLog」 — ダイバージェンスアラートのシグナルを受け取る場所です。

「Div」 — 「RSI Divergence Complete」または「RSI Divergence Forming」シグナルを設定します。

「EI」 — 追加インジケーターのアラートを設定します：価格到達アラート、サポート／レジスタンス接近アラート、EMA/Bollinger Band/Supertrend アラート。（「Extra Indicators」）

「Webhook」 — Proユーザーのみ表示。TradingView のwebhookを受信して、強力なアラーム、シグナルの組み合わせ、自動注文を実現します。

「Setting」 — アラーム種別、サウンド、紹介報酬の設定、お知らせ、紹介通知を設定します。

📊 シグナル通知（「DivLog」）の確認

「DivLog」は、ダイバージェンスのアラートシグナルを受け取る場所です。

  1. 最大150件のシグナルを保存します。定期的に整理してください。
  2. 未確認のアラートを表示します。チェックを付けるとアラームを解除できます。未確認の最新5件まで表示されます。
  3. 見たいシグナルだけに絞り込めます。

🔍 シグナル詳細を見る

各アラートをタップすると、シグナルの詳細情報を確認できます。

RSI のダイバージェンスアラートでは、開始・終了価格、RSI の値、タイムスタンプを確認できます。

「DivForming」は、シグナル発生時点で他の時間足に形成中のダイバージェンスを表示します。

「OutsideBB」は、シグナル発生時にどの時間足がボリンジャーバンドの外側だったかを表示します。

  • シグナルの時間足より小さい時間足では、シグナル時点（at now）でボリンジャーバンドの外側だったローソク足を表示します。
  • シグナルの時間足より大きい時間足では、後から確定する RSI ダイバージェンスのピーク（at peak）時点でボリンジャーバンドの外側だったローソク足を表示します。

例

上の例では、15mの時間足で強気シグナルが発生しています。

「DivForming」は、30mと1hの時間足で弱気ダイバージェンスが形成中であることを示します。

「OutsideBB」の表示：

  • シグナル時点では、5mの時間足がボリンジャーバンドの外側でした。
  • RSI のダイバージェンスピーク時点では、15m、30m、1hの時間足がボリンジャーバンドの外側でした。

⚙️ RSI ダイバージェンスアラート設定（「Div」）

RSI ダイバージェンスの全体設定

  1. 設定する銘柄を選択します。
  2. 「RSI Divergence Complete」と「RSI Divergence Forming」のどちらのシグナルにするかを選びます。
  3. 一括設定エリア — 下の項目すべてに設定をまとめて適用します。
  4. +ボタンでダイバージェンスのフィルターを追加します。
  5. フィルターを推奨デフォルト設定にリセットします。
  6. 価格条件を一括で設定します。

フィルター個別設定

  1. Configure individual RSI divergence signals to receive:

    (a) 希望の時間足を選択します。「RSI Divergence Forming」の場合は、「メイン時間足」と「サブ時間足」の両方を選びます。メイン時間足でダイバージェンスが形成中の状態で、小さい時間足に RSI のピークが出たタイミング（価格反転）でアラートが鳴ります。

    (b) シグナルを選択：「Bull（強気）」または「Bear（弱気）」。青＝アラートON、グレー＝OFF。

    (c) 売られすぎ／買われすぎのしきい値を設定します。「starting RSI」が売られすぎ水準を下回ると強気アラート、「starting RSI」が買われすぎ水準を上回ると弱気アラートになります。

    (d) アラームの種類と音を設定します。詳細は設定ページで行えます：

    A 強制アラーム（ループ）— 手動で停止するまで鳴り続けます。サイレントモードを無視します

    B 強制アラーム（1回）— 1回だけ鳴ります。サイレントモードを無視します

    C 端末設定に従う — 端末の通常のサウンド設定を使用します

    D バイブのみ — 音なしで振動します

    E サイレント — 音も振動もありません

    (e) 有用なシグナルだけに絞るため、追加条件を設定します：価格条件、別時間足のRSI形成条件、ボリンジャーバンド条件。

e0) 条件を複数設定した場合は、関係を設定します：「and」（すべて満たす）または「or」（いずれか1つ満たす）。

e1) 価格条件を設定 — ダイバージェンスの開始／終了価格が、指定価格より上／下のときにアラートします。

e2) 別の時間足でダイバージェンスが形成中のときにアラートします。

e3) RSI ダイバージェンスの最終ピーク価格が、ボリンジャーバンドの外側かどうかを確認します。

戦略のヒント

  • レジスタンス、トレンドライン、フィボナッチなど、他の指標と必ず組み合わせましょう。
  • 他の指標と同様に、RSI ダイバージェンスは100%正確ではありませんが、勝率を高めます。
  • 1分・5分のダイバージェンスは見送られがちですが、信頼度は 15分 ＜ 1時間 ＜ 4時間 の順に上がります。4時間足のダイバージェンスは信頼度が高く、A級アラームに設定するのがおすすめです。

📈 追加インジケーターアラート（「EI」）

  1. 設定する銘柄を選択します。
  2. 銘柄の価格アラートを設定します。
  3. EMA（指数移動平均）クロスのアラートを設定します。
  4. サポート／レジスタンスへの接近アラートを設定します。
  5. ボリンジャーバンドのブレイクアウトアラートを設定します。
  6. Supertrendの転換アラートを設定します。

※ 追加インジケーター（3、4、5、6）はログアウトするとリセットされます。

「Webhook」 — 上級者向けのPro機能です。

⚙️ 設定ページ

  1. アラーム種類（A、B…）とアラーム音（1、2…）を設定します。
  2. 自動発注を使う場合は、各取引所のAPIキーを入力します。
  3. 現在お使いのスマホに通知が届いているかをテストできます。自分宛てにテストメッセージを送ることで、設定したフィルターどおりにアラートが配信されているか確認できます。
  4. 紹介報酬に関するオプションを設定するページです。
  5. 全体向けのお知らせを受け取る場所です。
  6. 登録時に設定した紹介者からの限定お知らせを受け取る場所です。
  7. アプリ全体をライトモード／ダークモードに切り替えできます。

💰 紹介報酬

(a) あなたの紹介コード。このコードで他の人が購読すると、あなたが紹介者になります。

(b) あなたの招待リンク。このリンク経由で購読した人は、自動的にあなたが紹介者として登録されます。

(c) 紹介報酬の受取用ウォレットアドレスを入力します。BEP-20 USDT ウォレットが必要です（主要取引所のウォレット推奨）。入金が正しく行えるかは、DivAlarm のWebサイトの「My Info」からテストできます。

(d) 紹介報酬の状況を表示します：現在の紹介人数、見込み報酬額、確定額、支払済み額。

報酬は、紹介されたユーザーの購読支払い（無料トライアルを除く）から14日後に「見込み」から「確定」へ移行します。支払いは毎週火曜日のUTC 0:00に行われます。

紹介報酬の獲得方法

1] 設定 → 紹介報酬 → 報酬受取ウォレットアドレスを入力します。

2] 紹介リンクを共有します。相手はあなたのコード付きで購読ページへ移動します。

3] 相手が購読して支払いを行うと、報酬が入金されます。
