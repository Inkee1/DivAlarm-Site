📌 Pangkalahatang-ideya ng Menu

"DivLog" — Dito mo natatanggap ang mga signal ng divergence alert.

"Div" — I-configure ang mga signal na 'RSI Divergence Complete' o 'RSI Divergence Forming'.

"EI" — Mag-set up ng mga karagdagang alert ng indicator: mga alert kapag naabot ang presyo, mga alert kapag papalapit sa support/resistance, mga alert na EMA/Bollinger Band/Supertrend. ("Extra Indicators")

"Webhook" — Nakikita lang ng mga Pro user. Tumanggap ng mga TradingView webhook para sa mas makapangyarihang mga alarm, kombinasyon ng signal, at auto-orders.

"Setting" — I-configure ang mga uri ng alarm, mga tunog, mga setting ng referral reward, mga anunsyo, at mga notification ng referral.

📊 Pagtingin sa Mga Notification ng Signal ("DivLog")

Ang "DivLog" ang lugar kung saan mo natatanggap ang mga signal ng divergence alert.

  1. Hanggang 150 signal ang naka-store. Maglinis paminsan-minsan.
  2. Ipinapakita ang mga alert na hindi pa na-check. I-check ang marka para i-dismiss ang alarm. Maximum na 5 pinakabagong hindi pa na-check na alert ang ipinapakita.
  3. I-filter para makita lang ang mga signal na gusto mo.

⚙️ RSI Mga Setting ng Divergence Alert ("Div")

Pangkalahatang RSI Mga Setting ng Divergence

  1. Piliin kung aling coin ang iko-configure.
  2. Pumili sa pagitan ng mga signal na 'RSI Divergence Complete' at 'RSI Divergence Forming'.
  3. Batch settings area — ilapat ang mga setting sa lahat ng item sa ibaba nang sabay-sabay.
  4. Magdagdag ng mga divergence filter gamit ang + button.
  5. I-reset ang mga filter sa inirerekomendang default na mga setting.
  6. Itakda ang mga kondisyon ng presyo nang batch.

Mga Setting ng Indibidwal na Filter

  1. I-configure ang mga indibidwal na RSI divergence signal na tatanggapin:

    (a) Piliin ang gustong timeframe. Para sa 'RSI Divergence Forming', piliin ang parehong 'main timeframe' at 'sub timeframe'. Magti-trigger ang mga alert kapag nabuo ang RSI peak sa mas maliit na timeframe habang nabubuo ang divergence sa main timeframe (price reversal).

    (b) Pumili ng mga signal: "Bull(bullish)" o "Bear(bearish)". Asul = naka-enable ang alerts, Abo = naka-disable.

    (c) Itakda ang oversold/overbought thresholds. Bullish alert kapag ang 'starting RSI' ay mas mababa sa oversold level; bearish kapag ang 'starting RSI' ay mas mataas sa overbought level.

    (d) I-configure ang uri ng alarm at tunog. Nasa Settings page ang detalyadong mga setting:

    A Force Alarm (Loop) — tuloy-tuloy na tutunog hanggang manu-manong ihinto, hindi pinapansin ang silent mode

    B Force Alarm (Once) — tutunog nang isang beses, hindi pinapansin ang silent mode

    C Sundin ang Settings ng Phone — ginagamit ang normal na sound settings ng device

    D Vibrate Only — vibration lang, walang tunog

    E Silent Mode — walang tunog o vibration

    (e) Magtakda ng mga karagdagang kondisyon para sa mga kapaki-pakinabang na signal lang: mga kondisyon ng presyo, forming conditions ng RSI sa ibang timeframe, mga kondisyon ng Bollinger Band.

e0) Kapag maraming kondisyon ang naka-set, i-configure ang relasyon: "and" (lahat ay dapat matugunan) o "or" (kahit isa lang ang matugunan).

e1) Itakda ang mga kondisyon ng presyo — mag-aalert kapag ang divergence start/end price ay mas mataas/mas mababa sa isang partikular na presyo.

e2) Mag-alert kapag nabubuo ang divergence sa ibang timeframe.

e3) Suriin kung ang huling peak price ng RSI divergence ay nasa labas ng Bollinger Bands.

Mga Tip sa Strategy

  • Laging pagsamahin sa iba pang indicators: resistance, trendlines, Fibonacci, atbp.
  • Gaya ng lahat ng indicators, hindi 100% accurate ang RSI divergence — pinapataas nito ang probability.
  • Madalas binabalewala ang 1m, 5m divergences, pero tumataas ang reliability: 15m < 1h < 4h. Napaka-reliable ng 4h divergence — inirerekomendang i-set bilang A-grade alarm.

📈 Mga Karagdagang Indicator Alerts ("EI")

  1. Piliin kung aling coin ang iko-configure.
  2. Mag-set ng price alerts para sa coin.
  3. I-configure ang EMA (Exponential Moving Average) cross alerts.
  4. Mag-set ng support/resistance approach alerts.
  5. I-configure ang Bollinger Band breakout alerts.
  6. Mag-set ng Supertrend change alerts.

※ Ang mga karagdagang indicators (3, 4, 5, 6) ay nagre-reset kapag nag-log out ka.

💰 Mga Referral Rewards

(a) Ang referral code mo. Kapag nag-subscribe ang iba gamit ang code na ito, ikaw ang magiging referrer nila.

(b) Ang invite link mo. Sinumang mag-subscribe sa pamamagitan ng link na ito ay awtomatikong magrerehistro sa’yo bilang referrer nila.

(c) Ilagay ang wallet address mo para sa referral rewards. Dapat ay BEP-20 USDT wallet (inirerekomenda ang mga wallet ng major exchanges). Maaari mong i-test kung gumagana nang tama ang deposits mula sa 'My Info' sa DivAlarm website.

(d) Ipinapakita ang status ng referral rewards mo: kasalukuyang bilang ng referrals, posibleng halaga ng reward, confirmed na halaga, at paid na halaga.

Lililipat ang rewards mula 'potential' papuntang 'confirmed' 14 na araw matapos ang subscription payment ng na-refer na user (hindi kasama ang free trial). Ang payouts ay lingguhan tuwing Martes sa UTC midnight.

Paano Kumita ng Referral Rewards

1] Pumunta sa Settings → Referral Rewards → Ilagay ang reward wallet address mo.

2] Ibahagi ang iyong referral link. Ididirekta ang iba sa pahina ng subscription gamit ang iyong code.

3] Kapag nag-subscribe at nagbayad sila, ide-deposito ang mga reward.
