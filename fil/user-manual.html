📌 Pangkalahatang-ideya ng Menu

📊 Pagtingin sa Mga Notification ng Signal ("DivLog")

Ang "DivLog" ang lugar kung saan mo natatanggap ang mga divergence alert signal.

  1. Hanggang 150 signal ang nase-save. Maglinis paminsan-minsan.
  2. Ipinapakita ang mga alert na hindi pa na-check. I-check ang mark para i-dismiss ang alarm. Max na 5 pinakabagong hindi pa na-check na alert ang ipinapakita.
  3. I-filter para ang makita mo lang ay ang mga signal na gusto mo.

🔍 Tingnan ang Detalye ng Signal

Sa pag-tap sa bawat alert, makikita mo ang detalyadong impormasyon ng signal.

Para sa mga RSI Divergence alert, makikita mo ang start at end price, mga value ng RSI, at mga timestamp.

"DivForming" ipinapakita ang mga divergence na nabubuo sa ibang timeframe sa mismong sandaling lumabas ang signal.

"OutsideBB" ipinapakita kung aling mga timeframe ang nasa labas ng Bollinger Bands noong lumabas ang signal.

  • Para sa mga timeframe na mas maliit kaysa sa timeframe ng signal, ipinapakita nito kung aling mga candle ang nasa labas ng Bollinger Band sa sandali ng signal (at now).
  • Para sa mga timeframe na mas malaki kaysa sa timeframe ng signal, ipinapakita nito kung aling mga candle ang nasa labas ng Bollinger Band sa mas huling RSI divergence peak (at peak).

Halimbawa

Sa halimbawa sa itaas, may Bullish signal sa 15m timeframe.

"DivForming" ay nagpapahiwatig na may nabubuong bearish divergences sa 30m at 1h timeframes.

"OutsideBB" ay nagpapakita ng:

  • Sa mismong sandali ng signal, ang 5m timeframe ay nasa labas ng Bollinger Band.
  • Sa RSI divergence peak, ang 15m, 30m, at 1h timeframes ay nasa labas ng Bollinger Band.

⚙️ RSI Mga Setting ng Divergence Alert ("Div")

Pangkalahatang RSI Mga Setting ng Divergence

  1. Piliin kung aling coin ang iko-configure.
  2. Pumili sa pagitan ng 'RSI Divergence Complete' at 'RSI Divergence Forming' na mga signal.
  3. Batch settings area — i-apply ang settings sa lahat ng item sa ibaba nang sabay-sabay.
  4. Magdagdag ng divergence filters gamit ang + button.
  5. I-reset ang filters sa inirerekomendang default settings.
  6. I-set ang mga kondisyon ng presyo nang batch.

Mga Setting ng Bawat Filter

  1. Configure individual RSI divergence signals to receive:

    (a) Piliin ang gustong timeframe. Para sa 'RSI Divergence Forming', piliin ang parehong 'main timeframe' at 'sub timeframe'. Magti-trigger ang alerts kapag nabuo ang RSI peak sa mas maliit na timeframe habang nabubuo ang divergence sa main timeframe (price reversal).

    (b) Piliin ang signals: "Bull(bullish)" o "Bear(bearish)". Asul = naka-enable ang alerts, Gray = naka-disable.

    (c) Itakda ang oversold/overbought thresholds. Bullish alerts kapag ang 'starting RSI' ay mas mababa sa oversold level; bearish kapag ang 'starting RSI' ay mas mataas sa overbought level.

    (d) I-configure ang uri ng alarm at tunog. Nasa Settings page ang detalyadong settings:

    A Force Alarm (Loop) — tuloy-tuloy na tutunog hanggang manu-manong ihinto, hindi pinapansin ang silent mode

    B Force Alarm (Once) — tutunog nang isang beses, hindi pinapansin ang silent mode

    C Sundin ang Settings ng Phone — gagamit ng normal na sound settings ng device

    D Vibrate Only — vibration lang, walang tunog

    E Silent Mode — walang tunog o vibration

    (e) Magtakda ng dagdag na kondisyon para mga kapaki-pakinabang na signal lang: mga kondisyon ng presyo, ibang timeframe RSI forming conditions, at Bollinger Band conditions.

e0) Kapag maraming kondisyon ang naka-set, i-configure ang relasyon: "and" (lahat dapat matugunan) o "or" (kahit isa lang ang matugunan).

e1) Itakda ang mga kondisyon ng presyo — mag-alert kapag ang divergence start/end price ay mas mataas/mas mababa sa isang partikular na presyo.

e2) Mag-alert kapag nabubuo ang divergence sa ibang timeframe.

e3) I-check kung ang RSI divergence final peak price ay nasa labas ng Bollinger Bands.

Mga Tip sa Strategy

  • Laging i-combine sa ibang indicators: resistance, trendlines, Fibonacci, atbp.
  • Gaya ng lahat ng indicators, hindi 100% accurate ang RSI divergence — pinapataas lang nito ang probability.
  • Madalas binabalewala ang 1m, 5m divergences, pero tumataas ang reliability: 15m < 1h < 4h. Napaka-reliable ng 4h divergence — inirerekomendang i-set bilang A-grade alarm.

📈 Mga Karagdagang Alert sa Indicator ("EI")

  1. Piliin kung aling coin ang iko-configure.
  2. Mag-set ng price alerts para sa coin.
  3. I-configure ang EMA (Exponential Moving Average) cross alerts.
  4. Mag-set ng alerts kapag lumalapit sa support/resistance.
  5. I-configure ang Bollinger Band breakout alerts.
  6. Mag-set ng alerts sa pagbabago ng Supertrend.

※ Ang mga karagdagang indicator (3, 4, 5, 6) ay nagre-reset kapag nag-log out ka.

💰 Referral Rewards

(d) Ipinapakita ang status ng referral rewards mo: kasalukuyang bilang ng referrals, posibleng reward amount, confirmed amount, at paid amount.

Lililipat ang rewards mula 'potential' papuntang 'confirmed' pagkalipas ng 14 araw matapos ang subscription payment ng na-refer na user (hindi kasama ang free trial). Lingguhan ang bayad tuwing Martes, UTC midnight.

Paano Kumita ng Referral Rewards

1] Pumunta sa Settings → Referral Rewards → Ilagay ang reward wallet address mo.

2] I-share ang referral link mo. Madidirekta ang iba sa page ng subscription gamit ang code mo.

3] Kapag nag-subscribe at nagbayad sila, awtomatikong maide-deposit ang rewards.
