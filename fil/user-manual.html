📌 Overview ng Menu

"DivLog" — Dito mo natatanggap ang mga divergence alert signal.

"Div" — I-configure ang mga signal na 'RSI Divergence Complete' o 'RSI Divergence Forming'.

"EI" — Mag-set up ng dagdag na indicator alerts: price reach alerts, support/resistance approach alerts, EMA/Bollinger Band/Supertrend alerts. ("Extra Indicators")

"Webhook" — Makikita lang ng Pro users. Tumanggap ng TradingView webhooks para sa mas powerful na alarms, kombinasyon ng signals, at auto-orders.

"Setting" — I-configure ang mga uri ng alarm, tunog, referral reward settings, announcements, at referral notifications.

📊 Pagtingin sa Signal Notifications ("DivLog")

Ang "DivLog" ang lugar kung saan mo natatanggap ang mga divergence alert signal.

  1. Hanggang 150 signals ang nase-save. Maglinis paminsan-minsan.
  2. Ipinapakita ang mga alert na hindi pa na-check. I-check ang mark para i-dismiss ang alarm. Max 5 pinakabagong hindi pa na-check na alerts ang ipinapakita.
  3. I-filter para ang makita mo lang ay ang mga signal na gusto mo.

⚙️ RSI Settings ng Divergence Alert ("Div")

Pangkalahatang RSI Settings ng Divergence

  1. Piliin kung aling coin ang iko-configure.
  2. Pumili sa pagitan ng 'RSI Divergence Complete' vs 'RSI Divergence Forming' signals.
  3. Batch settings area — i-apply ang settings sa lahat ng items sa ibaba nang sabay-sabay.
  4. Magdagdag ng divergence filters gamit ang + button.
  5. I-reset ang filters sa inirerekomendang default settings.
  6. I-set ang price conditions nang batch.

Settings ng Bawat Filter

  1. Configure individual RSI divergence signals to receive:

    (a) Piliin ang gustong timeframe. Para sa 'RSI Divergence Forming', piliin pareho ang 'main timeframe' at 'sub timeframe'. Magti-trigger ang alerts kapag nabuo ang RSI peak sa mas maliit na timeframe habang nabubuo ang divergence sa main timeframe (price reversal).

    (b) Piliin ang signals: "Bull(bullish)" o "Bear(bearish)". Blue = naka-enable ang alerts, Gray = naka-disable.

    (c) I-set ang oversold/overbought thresholds. Bullish alert kapag ang 'starting RSI' ay mas mababa sa oversold level; bearish kapag ang 'starting RSI' ay mas mataas sa overbought level.

    (d) I-configure ang uri ng alarm at tunog. Nasa Settings page ang detalyadong settings:

    A Force Alarm (Loop) — tuloy-tuloy na tutunog hanggang i-stop nang manual, hindi pinapansin ang silent mode

    B Force Alarm (Once) — tutunog nang isang beses, hindi pinapansin ang silent mode

    C Sundin ang Settings ng Phone — gagamit ng normal na sound settings ng device

    D Vibrate Lang — vibration lang, walang tunog

    E Silent Mode — walang tunog o vibration

    (e) Mag-set ng mga dagdag na kondisyon para sa mga kapaki-pakinabang na signal lang: mga kondisyon sa presyo, mga kondisyon sa pagbuo sa ibang timeframe RSI, at mga kondisyon sa Bollinger Band.

e0) Kapag maraming kondisyon ang naka-set, i-configure ang relasyon: "and" (lahat dapat matugunan) o "or" (kahit isa lang ang matugunan).

e1) Mag-set ng kondisyon sa presyo — mag-alert kapag ang start/end price ng divergence ay mas mataas/mas mababa sa isang partikular na presyo.

e2) Mag-alert kapag nabubuo ang divergence sa ibang timeframe.

e3) I-check kung ang final peak price ng RSI divergence ay nasa labas ng Bollinger Bands.

Mga Tip sa Strategy

  • Laging i-combine sa ibang indicators: resistance, trendlines, Fibonacci, atbp.
  • Gaya ng lahat ng indicators, hindi 100% accurate ang RSI divergence — pinapataas lang nito ang probability.
  • Madalas binabalewala ang 1m, 5m divergences, pero tumataas ang reliability: 15m < 1h < 4h. Napaka-reliable ng 4h divergence — inirerekomendang i-set bilang A-grade alarm.

📈 Mga Dagdag na Alert sa Indicator ("EI")

  1. Piliin kung aling coin ang iko-configure.
  2. Mag-set ng price alerts para sa coin.
  3. I-configure ang EMA (Exponential Moving Average) cross alerts.
  4. Mag-set ng alerts kapag lumalapit sa support/resistance.
  5. I-configure ang Bollinger Band breakout alerts.
  6. Mag-set ng alerts sa pagbabago ng Supertrend.

※ Ang mga dagdag na indicator (3, 4, 5, 6) ay nagre-reset kapag nag-log out ka.

💰 Mga Referral Reward

(a) Ang referral code mo. Kapag may nag-subscribe gamit ang code na ito, ikaw ang magiging referrer nila.

(b) Ang invite link mo. Sinumang mag-subscribe gamit ang link na ito ay awtomatikong mare-register ka bilang referrer nila.

(c) Ilagay ang wallet address mo para sa referral rewards. Dapat ay BEP-20 USDT wallet (inirerekomenda ang mga wallet ng major exchange). Maaari mong i-test kung tama ang pagpasok ng deposit mula sa 'My Info' sa website ng DivAlarm.

(d) Ipinapakita ang status ng referral rewards mo: kasalukuyang bilang ng referrals, posibleng halaga ng reward, confirmed na halaga, at paid na halaga.

Ang rewards ay lilipat mula sa “potential” papuntang “confirmed” 14 na araw matapos ang bayad sa subscription ng na-refer na user (hindi kasama ang free trial). Ang payouts ay lingguhan tuwing Martes, UTC midnight.

Paano Kumita ng Referral Rewards

1] Pumunta sa Settings → Referral Rewards → Ilagay ang wallet address mo para sa rewards.

2] I-share ang referral link mo. Madadala ang iba sa subscription page gamit ang code mo.

3] Kapag nag-subscribe at nagbayad sila, ide-deposit ang rewards.
