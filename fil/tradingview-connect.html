Pagsubok ng koneksyon

Nagpapadala ang server ng test signal sa iyong Android app at ipinapakita ang resulta dito. Ang test na ito ay HINDI kailanman maglalagay ng order.

Mag-sign in gamit ang account na ginagamit mo sa DivAlarm app.

Mag-sign in gamit ang email

Wala pang webhook URL ang account na ito. Buksan muna ang DivAlarm app gamit ang account na ito, pagkatapos i-reload ang page na ito.

  1. TradingView
    Ang page na ito ang pansamantalang kapalit ng TradingView habang nagte-test.
  2. Server ng DivAlarm
    Sinusuri ang iyong URL at plan, tapos ipinapasa sa iyong phone.
  3. Ang iyong phone
    Kinukumpirma ng DivAlarm app na natanggap nito ang signal.

Hindi isinasama ng test ang keyword matching at mga awtomatikong order, at hindi binabawas sa iyong libreng allowance.

Kung nakumpirma ng telepono na natanggap ang signal pero walang lumabas na banner, payagan ang mga pop-up para sa Pagsubok ng koneksyon ng Webhook sa notification settings ng DivAlarm sa iyong telepono. Suriin din kung naka-on ang Huwag Istorbohin.

I-set up ang iyong TradingView alert

  1. Kopyahin ang iyong webhook URL at i-enable ang AA

    Sa DivAlarm, buksan ang Alarm sa keyword · Mga awtomatikong order → Mga keyword sa webhook, idagdag ang AA at i-on ang alarm nito. Kopyahin ang webhook URL sa ibaba habang naka-sign in sa parehong account ng iyong phone.

    Mag-sign in gamit ang app account mo para makita ang iyong URL

    Panatilihing pribado ang address na ito. Sinumang may hawak nito ay maaaring magpadala ng signal sa iyong account.

    Para subukan lang ang alarm, i-off ang auto-orders para sa anumang keyword o kombinasyon na tumutugma sa AA.

    Screenshot ng keyword setup

  2. Idagdag ang iyong URL sa isang TradingView alert

    I-right click ang chart at piliin ang Magdagdag ng alert. Buksan ang Mga Notipikasyon, i-check ang Webhook URL, i-paste ang iyong address at pindutin ang I-apply.

    Gamitin ang parehong URL para sa ibang mga alert. Kung ang bagong alert ay nagpapakita na ng iyong address, tiyakin na naka-enable ang Webhook URL. Para sa kasalukuyang alert, tingnan ang sariling mga setting nito.

    Mga screenshot ng TradingView alert at webhook
    Video · Ikonekta ang TradingView sa DivAlarm
    Manood sa YouTube

  3. Pumili ng one-time na price condition

    Para sa mabilisang check, piliin ang Presyo → Labas ng Channel. Halimbawa, kung ang kasalukuyang presyo ay 100, itakda ang lower bound sa 98 at upper bound sa 99. Piliin ang Isang beses lang. Para sa indicator alert, piliin ang indicator condition na gusto mong gamitin.

    Screenshot ng price condition

  4. Isama ang AA sa mensahe

    Buksan ang Mensahe sa TradingView, isama ang parehong AA keyword na in-enable mo sa app at pindutin ang I-apply. Kopyahin ang halimbawa sa ibaba. Kung ang rule mo ay tumutugma sa simula ng mensahe, ilagay muna ang AA.

    AA Webhook test

    Para isama ang symbol at presyo, gamitin ang AA {{ticker}} {{close}}. Pinapalitan ng TradingView ang placeholders kapag nag-fire ang alert.

    Screenshot ng mensahe

  5. Gumawa ng alert at tingnan ang iyong phone

    Pindutin ang Gumawa at maghintay ng price update. Hanapin ang event sa TradingView alert log, tapos tingnan ang AA alarm sa DivAlarm. I-off ang test rule at ang TradingView test alert kapag tapos na.

    Kung hindi dumating ang alarm
    • Kung walang laman ang TradingView alert log, tiyaking active ang alert at natugunan ng presyo ang condition.
    • Kung may delivery failure sa event, tingnan ang Status ng Webhook sa alert log at ang URL na naka-save sa alert na iyon. Kung hindi available ang opsyon na Webhook URL, tingnan ang dalawang-hakbang na pagpapatotoo sa TradingView.
    • Kung nagpadala na ng alert ang TradingView, tingnan ang mode ng Mga keyword sa webhook, ang AA rule at alarm switch nito, at ang notification permission ng DivAlarm sa iyong phone.
