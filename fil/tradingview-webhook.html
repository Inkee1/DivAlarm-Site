Pumili ng Pinagmulan ng Keyword

Buksan ang Alarm sa keyword · Mga awtomatikong order at pumili ng input sa itaas ng pahina. I-tap ang ? sa tabi ng selector para sa tulong. Parehong mode ay gumagamit ng iyong mga naka-save na keyword, kombinasyon, at setting ng alarm. Bawat account ay maaaring sumubok ng 5 libreng keyword alarm, walang kailangan card. Ang Auto-Order ay nananatiling Pro-only.

5 libreng execution bawat account: Ang mga keyword sa notification ng telepono, mga keyword sa webhook, at pinagsamang alarm ay iisa lang ang lifetime allowance. Mabibilang ang paggamit kapag matagumpay na naiskedyul ang tumugmang alarm sa iyong telepono. Hindi mababawas ang credit sa hindi tumugma, duplicate na delivery, o nabigong pag-schedule. Kailangan ng internet para ma-verify ang libreng paggamit.

Ang allowance ay hiwalay sa 7 pangkalahatang alarm, hindi nare-reset kahit i-reinstall, at hindi kasama ang mga awtomatikong order. Mananatili ang iyong mga panuntunan kahit matapos ang 5 gamit; piliin ang Pro para magpatuloy.

Mga keyword sa notification ng telepono (Android)

  1. Piliin ang Mga keyword sa notification ng telepono.
  2. Buksan ang notification access settings mula sa pahina at payagan ang DivAlarm na basahin ang mga notification.
  3. Magdagdag ng teksto sa Isama ang Keyword na lumalabas sa pamagat o katawan ng notification na gusto mong tumugma.
  4. Kapag may dumating na tumutugmang notification, ia-apply ng DivAlarm ang iyong naka-configure na alarm, kombinasyon, at auto-order na mga panuntunan.

Dapat manatiling naka-enable ang notification access para mabasa ang ibang app. Tanging text na ibinibigay ng Android lang ang pwedeng itugma ng DivAlarm; hindi isinasama ang grouped summaries, paulit-ulit na kopya, at mga notification ng alarm o resulta ng order na ginawa ng DivAlarm. Para sa messaging notifications, ang pinakabagong mensahe lang ang tinitingnan.

Ang sariling papasok na signal ng DivAlarm ay pwedeng mag-trigger ng keyword alarm at order sa mode na ito. Patuloy na umiiral ang mga naka-enable mong filter. Pwede mo pa ring gamitin ang @D, @E, at @P signal keywords.

Mga keyword sa webhook

Piliin ang Mga keyword sa webhook para tumanggap ng mga mensahe na ipinapadala sa iyong personal na webhook URL, kabilang ang mga alert ng TradingView. Lalabas lang ang URL at copy button sa mode na ito. Sundin ang TradingView na mga hakbang sa setup sa ibaba.

Mananatili ang iyong mga naka-save na panuntunan kahit magpalit ng mode. Sa phone mode, hindi magti-trigger ng keyword alarm o order ang mga webhook message sa device na ito. Ang mga kasalukuyang user ay magsisimula sa webhook mode, kaya magpapatuloy ang kanilang kasalukuyang webhook setup hanggang magpalit sila.

Ang pagbasa ng notification ng ibang app ay tampok ng Android; hindi ito available sa iOS o web.

🔔 Mga Panuntunan sa Keyword at Pag-setup ng TradingView Webhook

Sa Alarm sa keyword · Mga awtomatikong order, idagdag ang text na gusto mong itugma sa Isama ang Keyword. Sine-check ng phone mode ang pamagat at katawan ng notification; sine-check ng webhook mode ang papasok na webhook text. Piliin ang iyong source bago subukan ang panuntunan.

Pagdagdag ng Webhook sa TradingView

Piliin ang Mga keyword sa webhook, idagdag ang AA sa Isama ang Keyword, at i-on ang alarm nito. Huwag i-on ang mga awtomatikong order para sa anumang panuntunan ng keyword o kombinasyon na tumutugma sa AA habang sinusubukan ang totoong alert ng TradingView. Palawakin ang Webhook URL para makopya ang iyong personal na URL. I-tap ang ? sa tabi ng heading ng URL para sa mga hakbang na may larawan.

I-right click ang indicator na gusto mong pagkunan ng signal sa TradingView at i-click ang "Magdagdag ng Alerto sa ~".

Buksan ang Mga Notification, i-enable ang Webhook URL, i-paste ang iyong personal na URL, at piliin ang Ilapat.

Maaari mong gamitin muli ang parehong URL para sa iba pang mga alerto. Kung ang bagong alerto ay may iyong URL na, tiyaking naka-enable ang checkbox at tama ang address. Suriin ang bawat umiiral na alerto nang paisa-isa.

Para sa isang beses na pagsubok ng presyo, piliin ang Presyo → Labas ng Channel at Isang beses lang. Itakda ang parehong hangganan sa isang gilid ng kasalukuyang presyo. Halimbawa, kung ang presyo ay 100, gamitin ang lower bound na 98 at upper bound na 99.

Gumagamit ang TradingView at mga screenshot ng app ng AAA para ipakita kung saan ilalagay ang keyword. Para sa test na ito, ilagay ang AA Webhook test sa Mensaheng Ipapadala o idagdag ang iyong rehistradong keyword na AA sa kasalukuyang mensahe, pagkatapos ay ilapat ang pagbabago.

Piliin ang Lumikha. Kapag natugunan ang kondisyon, tingnan ang log ng alerto ng TradingView at ang alarm sa iyong telepono.

Pagtanggap ng mga TradingView Alert sa App

Panatilihing naka-select ang Mga keyword sa webhook. Ang mensaheng naglalaman ng AA ay magti-trigger ng alarm na in-enable mo para sa keyword na iyon. I-off ang AA test rule kapag tapos ka na.

Para suriin ang delivery mula server papunta sa iyong Android phone, magpadala ng test signal mula sa connection test. Ang diagnostic na ito ay hindi dumadaan sa mga panuntunan ng keyword at hindi naglalagay ng order sa exchange at hindi gumagamit ng iyong libreng allowance ng alarm.

🤖 Auto-Order gamit ang Alarm sa keyword

Sa Pro, maaari kang magdagdag ng mga awtomatikong order sa bawat panuntunan ng keyword o kombinasyon. Panatilihing naka-off ang mga awtomatikong order para sa mga panuntunang alarm lang. Kapag naka-enable, ang tugma mula sa napili mong source o eligible na signal ng DivAlarm ay maaaring maglagay ng totoong order sa iyong exchange.

Ilagay ang iyong exchange API keys sa Settings → Mga Setting ng Auto Order. Sinusuportahan ng Android app ang Binance, Bybit, OKX, Bitget, Gate, at Bitunix.

I-tap ang cart sa kanan ng keyword row para pumili ng exchange, symbol, at order settings, pagkatapos ay i-enable ang auto-orders para sa rule na iyon. Kung gagamit ka ng Bitget, tiyaking naka-check ang dalawang kinakailangang permiso sa Exchange API Key Setup.

📝 Pagrehistro ng mga Signal ng DivAlarm bilang Keyword

Ang sariling mga signal ng DivAlarm ay maaaring mag-trigger ng alarm sa keyword, mga kombinasyon, at mga awtomatikong order sa parehong input mode. Irehistro ang mga ito gamit ang mga format sa ibaba. Ang orihinal na naka-enable na filter ng signal ay nananatiling aktibo; ang pagdagdag ng keyword ay hindi mag-o-on ng naka-disable na filter ng signal.

RSI divergence (@D):
@D@Kind@Direction@Status@MainTimeframe[@SubTimeframe]

Ang mga status value ay early_completed, early_confirmed, confirmed, at forming. Ang pangalawang timeframe ay ginagamit para sa mga Forming signal.

Mga karagdagang indicator (@E):
@E@Kind@TitleKeyword@Timeframe

Mga alerto sa presyo (@P):
@P@Kind@TitleKeyword

Ang mga umiiral na @D na panuntunan na walang kinikilalang status ay patuloy na sinusuportahan; ang ika-apat at ika-limang field ay nananatiling para sa main at secondary timeframe.

Mga Uri ng Alarm:

  • @D — Mga filter ng RSI divergence
  • @E — Mga karagdagang indicator
  • @P — Mga alerto sa presyo

Mga Halimbawa

@D@BTC@Bull@forming@5m@1m

→ RSI divergence, BTCUSDT.P, may “Bull” sa pamagat, nabubuo pa ang signal; 5m ang pangunahing timeframe at 1m ang pangalawa

@D@ETH@Bear@confirmed@15m

→ RSI Divergence, ETHUSDT.P, title ay naglalaman ng "Bear", Confirmed, 15m, walang sub timeframe

@E@BTC@Sell@30m → Karagdagang indicator para sa BTC, may “Sell” sa pamagat, 30m

@E@BTC@Buy@1h

@E@ETH@Breakout@15m

@E@BTC@Breakdown@5m

@E@BTC@Near Support@1m

@E@BTC@Near Resistance@5m

@E@BTC@EMA50@1h

@P@BTC@Up → Alerto sa presyo ng BTC, may “Up” sa pamagat

🔀 Alarm sa Kombinasyon ng Signal

Pagsamahin ang mga tumugmang notification sa telepono o mga mensahe ng webhook mula sa napiling source kasama ang mga kwalipikadong signal ng DivAlarm para makagawa ng alarm sa kombinasyon. Ang mga patakaran ng keyword at setting ng bintana ng oras ay gumagana sa parehong mode.

Magtakda ng mga kondisyon na kailangang matugunan sa loob ng isang bintana ng oras para mag-trigger ang mga alarm.

Halimbawa:
Sa loob ng 1 oras 30 minuto:
• 'Alerto na may keyword A' AT
• 'Alerto na may keyword B' parehong dumating, O
• 'Alerto na may keyword C' dumating

Ilagay ang (1&2)|3 sa Kombinasyon ng Alarm at 1h 30m sa Bintana ng Oras.

& = "AT" (parehong kondisyon ay dapat matugunan)

| = "O" (kahit alin sa kondisyon ay maaaring matugunan)

Kahit naka-disable ang mga indibidwal na alarm sa keyword, puwedeng mag-trigger pa rin ang kombinasyon kapag natugunan ang mga kondisyon.

Puwede ring mag-auto-order gamit ang alarm sa kombinasyon!
