Выберите источник ключевого слова

Откройте Оповещения по ключевым словам · Автоордера и выберите источник вверху страницы. Нажмите ? рядом с селектором для справки. Оба режима используют ваши сохранённые ключевые слова, комбинации и настройки оповещений. Каждый аккаунт может бесплатно попробовать 5 оповещений по ключевым словам без карты — это общий лимит на все режимы за всё время. Автоордер остаётся доступен только в Pro.

5 бесплатных срабатываний на аккаунт: Ключевые слова уведомлений телефона, ключевые слова вебхуков и комбинированные оповещения используют общий пожизненный лимит. Использование засчитывается только при успешном планировании совпадающего оповещения на телефоне. Несовпадающие сообщения, дубли и ошибки планирования не расходуют лимит. Для проверки бесплатных использований требуется доступ в интернет.

Лимит отдельный от 7 общих оповещений, не сбрасывается при переустановке и не включает автоордера. Ваши правила сохраняются после всех 5 использований; выберите Pro для продолжения.

Ключевые слова уведомлений телефона (Android)

  1. Выберите Ключевые слова уведомлений телефона.
  2. Откройте настройки доступа к уведомлениям на странице и разрешите DivAlarm читать уведомления.
  3. Добавьте текст в Включить ключевое слово, который должен появиться в заголовке или теле уведомления для совпадения.
  4. Когда поступает совпадающее уведомление, DivAlarm применяет ваши настройки оповещений, комбинаций и автоордеров.

Доступ к уведомлениям должен оставаться включённым для чтения других приложений. DivAlarm может сопоставлять только текст, который предоставляет Android; групповые сводки, повторяющиеся копии и сгенерированные самим DivAlarm оповещения или уведомления о результатах ордеров игнорируются. Для сообщений проверяется только самое новое.

Собственные входящие сигналы DivAlarm также могут запускать оповещения по ключевым словам и ордера в этом режиме. Действуют их текущие включённые фильтры. Вы можете продолжать использовать ключевые слова сигналов @D, @E и @P.

Ключевые слова вебхуков

Выберите Ключевые слова вебхуков для получения сообщений, отправленных на ваш личный URL вебхука, включая оповещения TradingView. URL и кнопка копирования доступны только в этом режиме. Следуйте шагам настройки TradingView ниже.

Переключение режимов сохраняет ваши правила. В режиме телефона сообщения вебхука не запускают оповещения по ключевым словам или ордера на этом устройстве. Существующие пользователи начинают в режиме вебхука, поэтому их текущая настройка продолжается до переключения.

Чтение уведомлений других приложений — это функция Android; она недоступна на iOS и в веб-версии.

🔔 Правила ключевых слов и настройка вебхука TradingView

В Оповещения по ключевым словам · Автоордера добавьте текст для совпадения в Включить ключевое слово. Режим телефона проверяет заголовки и тела уведомлений; режим вебхука — входящий текст вебхука. Выберите источник перед тестированием правила.

Добавление вебхука в TradingView

Выберите Ключевые слова вебхуков, добавьте AA в Включить ключевое слово и включите его оповещение. Оставьте авто-ордера выключенными для любых правил или комбинаций, совпадающих с AA при тестировании реального оповещения TradingView. Разверните URL вебхука для копирования личного URL. Нажмите ? рядом с заголовком URL для пошаговой инструкции с иллюстрациями.

Щёлкните правой кнопкой мыши по индикатору, с которого хотите получать сигналы в TradingView, и выберите «Добавить оповещение на ~».

Откройте Уведомления, включите URL вебхука, вставьте личный URL и выберите Применить.

Вы можете использовать тот же URL для других оповещений. Если новое оповещение уже содержит ваш URL, убедитесь, что этот флажок включён и адрес указан правильно. Проверьте каждое существующее оповещение отдельно.

Для однократного теста цены выберите Price → Outside Channel и Once only. Установите оба предела с одной стороны от текущей цены. Например, если цена равна 100, используйте нижний предел 98 и верхний 99.

В TradingView и скриншотах приложения используется AAA, чтобы показать, куда вставлять ключевое слово. Для этого теста введите AA Webhook test в Message или добавьте зарегистрированное ключевое слово AA к существующему сообщению, затем примените изменения.

Выберите Create. Когда условие выполнится, проверьте журнал оповещений TradingView и тревогу на вашем телефоне.

Получение оповещений TradingView в приложении

Оставьте выбранным Ключевые слова вебхуков. Сообщение, содержащее AA, запускает оповещение, которое вы включили для этого ключевого слова. Отключите тестовое правило AA после завершения.

Чтобы проверить доставку с сервера на ваш Android, отправьте тестовый сигнал из теста подключения. Эта диагностика не использует правила ключевых слов и не отправляет ордера на биржу, а также не расходует ваш бесплатный лимит тревог.

🤖 Автоордер с оповещениями по ключевым словам

С Pro вы можете прикреплять автоордера к отдельным правилам ключевых слов или их комбинациям. Оставляйте автоордера выключенными для правил только с оповещениями. При включении совпадение из выбранного источника или подходящий сигнал DivAlarm может разместить реальный ордер на вашей бирже.

Введите API-ключи биржи в разделе Settings → Auto Order Settings. Приложение Android поддерживает Binance, Bybit, OKX, Bitget, Gate и Bitunix.

Нажмите корзину справа от строки ключевого слова, чтобы выбрать биржу, символ и настройки ордера, затем включите автоордера для этого правила. Если вы используете Bitget, проверьте два обязательных разрешения в Настройке API-ключа биржи.

📝 Регистрация сигналов DivAlarm как ключевых слов

Собственные сигналы DivAlarm могут запускать оповещения по ключевым словам, комбинации и автоордера в обоих режимах ввода. Регистрируйте их по приведённым ниже форматам. Исходные включённые фильтры сигнала сохраняются; добавление ключевого слова не активирует отключённый фильтр сигнала.

Дивергенция RSI (@D):
@D@Kind@Direction@Status@MainTimeframe[@SubTimeframe]

Значения статуса: early_completed, early_confirmed, confirmed и forming. Второй таймфрейм используется для сигналов со статусом forming.

Дополнительные индикаторы (@E):
@E@Kind@TitleKeyword@Timeframe

Ценовые оповещения (@P):
@P@Kind@TitleKeyword

Существующие правила @D без распознанного статуса остаются поддерживаемыми; их четвёртое и пятое поля сохраняют значения основного и дополнительного таймфреймов.

Типы тревог:

  • @D — фильтры дивергенции RSI
  • @E — дополнительные индикаторы
  • @P — ценовые оповещения

Примеры

@D@BTC@Bull@forming@5m@1m

→ Дивергенция RSI, BTCUSDT.P, заголовок содержит "Bull", Forming, основной 5м, дополнительный 1м

@D@ETH@Bear@confirmed@15m

→ Дивергенция RSI, ETHUSDT.P, заголовок содержит «Bear», Confirmed, 15м, без субтаймфрейма

@E@BTC@Sell@30m → Дополнительный индикатор, монета BTC, заголовок содержит "Sell", 30м

@E@BTC@Buy@1h

@E@ETH@Breakout@15m

@E@BTC@Breakdown@5m

@E@BTC@Near Support@1m

@E@BTC@Near Resistance@5m

@E@BTC@EMA50@1h

@P@BTC@Up → Ценовое оповещение, монета BTC, заголовок содержит "Up"

@P@ETH@Down

🔀 Комбинированные оповещения сигналов

Объединяйте совпадающие уведомления на телефон или сообщения вебхука из выбранного источника с подходящими сигналами DivAlarm для создания комбинированного оповещения. Правила ключевых слов и настройки временного интервала работают в обоих режимах.

Задайте условия, которые должны выполниться в течение временного интервала для срабатывания тревог.

Пример:
В течение 1 часа 30 минут:
• поступают оба оповещения с ключевым словом «A» И
• «B», ИЛИ
• поступает оповещение с ключевым словом «C»

Введите (1&2)|3 в Комбинация тревог и 1h 30m в Временной интервал.

& = «И» (оба условия должны быть выполнены)

| = «ИЛИ» (может быть выполнено любое из условий)

Даже если отдельные оповещения по ключевым словам отключены, комбинация всё равно может сработать при выполнении условий.

Автоордера также доступны для комбинированных оповещений!
