设置您的 TradingView 警报

  1. 复制您的 webhook URL 并启用 AA

    在 DivAlarm 中打开 关键词警报·自动下单 → Webhook 关键词，添加 AA 并开启其警报。请确保登录与手机相同的账户，然后复制下方 webhook URL。

    使用您的应用账户登录以查看您的 URL

    请妥善保管此地址。任何拥有它的人都能向您的账户发送信号。

    如仅需测试警报，请关闭所有匹配 AA 的关键词或组合的自动下单功能。

    关键词设置截图

  2. 将您的 URL 添加到 TradingView 警报

    右键点击图表，选择 添加警报。打开 通知，勾选 Webhook URL（Webhook 地址），粘贴您的地址并点击 应用。

    其他警报也使用同一 URL。若新警报已显示您的地址，请确认 Webhook URL 已启用。已有警报请检查其设置。

    TradingView 警报与 webhook 截图

  3. 选择一次性价格条件

    快速检查时，选择 价格 → 超出通道。例如当前价格为 100，设置下限为 98，上限为 99。选择 仅一次。如为指标警报，则选择所需的指标条件。

    价格条件截图

  4. 在消息中包含 AA

    在 TradingView 中打开 消息，包含您在应用中启用的相同 AA 关键词并点击 应用。复制下方示例。如规则需匹配消息开头，请将 AA 放在首位。

    AA Webhook test

    若要包含标的和价格，请使用 AA {{ticker}} {{close}}。TradingView 会在警报触发时替换占位符。

    消息截图

  5. 创建警报并检查手机

    点击 创建，等待价格更新。在 TradingView 警报日志 中找到事件，然后检查 DivAlarm 中的 AA 警报。完成后关闭测试规则和 TradingView 测试警报。

    若警报未收到
    • 若 TradingView 警报日志为空，确认警报已激活且价格满足条件。
    • 如事件显示发送失败，请检查警报日志中的 Webhook 状态 及该警报保存的 URL。如无 Webhook URL 选项，请检查 TradingView 的 双重认证。
    • 如 TradingView 已发送警报，请检查 Webhook 关键词 模式、AA 规则及其警报开关，以及手机上 DivAlarm 的通知权限。
