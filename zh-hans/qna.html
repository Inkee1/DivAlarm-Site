技术
为什么 RSI 数值与 TradingView 或其他平台略有不同？

RSI 数值使用 14 根 K 线 的平均值，且计算起点不同可能会导致数值略有差异。

此外，主要有两种计算方法：EMA（指数移动平均）和 SMA（简单移动平均）。

DivAlarm 计算 RSI 的方式能更好地反映近期趋势，因此与其他平台相比可能会出现细微差异。

账号
一个账号只能由一个人使用吗？

是，信号主要会发送到最近登录的设备。

如果同时在多台设备登录，部分信号仍可能在多台设备上收到；但为确保稳定运行，建议使用你最后登录的那台设备。

如遇到问题，请在 App 内进入 设置 → 同步设置，点击 “在此设备接收”，以确保功能正常。

平台
有 iPhone（iOS）版本吗？

与 Android 相比，Apple 的 iOS 有更严格得多的政策。

主要限制包括：

• 不允许强制响铃（可覆盖静音模式）
• 后台自动下单受限
• 推送通知送达更受限制

未来我们可能会为 iOS 发布一个功能受限版本，但目前尚无确定时间表。

功能
DivForming 里的“1m/1m”是什么意思？

1m/1m 设置会在 1 分钟图上的背离即将形成的瞬间触发提醒。

这意味着每当K 线趋势与 RSI 趋势开始出现背离时，你都会收到提醒——以尽可能早的时机捕捉潜在反转。

这非常适合希望在背离完全确认之前就收到通知的交易者。

技术
什么是 RSI 背离？为什么它很重要？

RSI 背离是指价格走势与RSI指标走势方向相反。

看涨背离：价格创出更低的低点，但 RSI 创出更高的低点 → 可能向上反转

看跌背离：价格创出更高的高点，但 RSI 创出更低的高点 → 可能向下反转

在技术分析中，RSI 背离被广泛认为是预测市场反转的最可靠指标之一。

功能
TradingView Webhook 集成如何工作？

订阅 Pro 后，你会获得一个专属 webhook URL，用于将 DivAlarm 连接到 TradingView。

功能包括：

• 可绕过静音模式的强力手机闹钟
• 组合信号——将多个提醒合并为一个
• 在支持的交易所进行自动下单执行

只需将你的 webhook URL 粘贴到 TradingView 的提醒设置中，并在提醒消息里加入特定关键词，即可触发对应动作。

功能
自动下单如何工作？

自动下单（仅 Pro）会在你选择的 TradingView 提醒触发时自动执行交易。

最多支持5 家交易所，你可以：

• 设置由特定提醒关键词触发的买/卖订单
• 配置下单数量、类型与条件
• 即使手机放在口袋里也能执行交易

注意：自动下单需要在你的交易所正确配置 API Key。
