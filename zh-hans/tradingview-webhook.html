选择关键词来源

打开 关键词警报·自动下单，在页面顶部选择一个输入。点击选择器旁的 ? 获取帮助。两种模式共用您保存的关键词、组合和警报设置。每个账户可终身免费试用 5 次关键词警报，无需信用卡。自动下单仅限 Pro。

每账户终身免费 5 次执行：手机通知关键词、Webhook 关键词和组合警报共用一个总额度。仅当成功在手机上调度匹配警报时计为一次使用。未匹配消息、重复推送和调度失败不计入额度。需联网以验证免费次数。

该额度 独立于 7 个通用警报，重装后不会重置，且不包含自动下单。5 次用完后，您的规则仍会保存；如需继续请升级 Pro。

手机通知关键词 (Android)

  1. 选择 手机通知关键词。
  2. 从页面打开通知访问设置，允许 DivAlarm 读取通知。
  3. 在 关键词包含 中添加您想匹配的通知标题或正文文本。
  4. 当匹配通知到达时，DivAlarm 会应用您配置的警报、组合和自动下单规则。

通知访问必须保持开启以读取其他应用。DivAlarm 只能匹配 Android 提供的文本；忽略分组摘要、重复副本及 DivAlarm 生成的警报或订单结果通知。消息通知仅检查最新消息。

DivAlarm 自身接收的信号也可在此模式触发关键词警报和下单，现有启用的过滤器依然生效。您可继续使用 @D、@E 和 @P 信号关键词。

Webhook 关键词

选择 Webhook 关键词，接收发送到您个人 Webhook URL 的消息，包括 TradingView 警报。URL 和复制按钮仅在此模式下显示。请按下方 TradingView 设置步骤 操作。

切换模式会保留您的已保存规则。在手机模式下，Webhook 消息不会在本设备触发关键词警报或下单。现有用户默认进入 Webhook 模式，当前 Webhook 设置会持续生效，直到切换。

读取其他应用通知是Android功能；iOS及网页版不支持。

🤖 关键词警报自动下单

使用 Pro，您可以为单个关键词规则或组合附加自动下单。仅限警报规则请保持自动下单关闭。启用后，来自您选择来源的匹配或符合条件的 DivAlarm 信号可在您的交易所下达真实订单。

在 设置 → 自动订单设置 中输入您的交易所 API 密钥。Android 应用支持 Binance、Bybit、OKX、Bitget、Gate 和 Bitunix。

点击关键词行右侧的 购物车 图标，选择交易所、交易对和订单设置，然后为该规则启用自动下单。如果您使用 Bitget，请检查 交易所 API 密钥设置 中的两个必需权限。

📝 注册 DivAlarm 信号为关键词

DivAlarm 自身信号可在 两种输入模式 中触发关键词警报、组合和自动下单。请按以下格式注册。信号原有启用的过滤器仍然生效；添加关键词不会启用已禁用的信号过滤器。

RSI 背离（@D）：
@D@Kind@Direction@Status@MainTimeframe[@SubTimeframe]

状态值为 early_completed、early_confirmed、confirmed 和 forming。第二时间框架用于形成中信号。

额外指标（@E）：
@E@Kind@TitleKeyword@Timeframe

价格警报（@P）：
@P@Kind@TitleKeyword

未识别状态的现有 @D 规则仍受支持；其第四和第五字段保持主时间框架和次时间框架的含义。

警报类型：

  • @D — RSI 背离过滤器
  • @E — 额外指标
  • @P — 价格警报

示例

@D@BTC@Bull@forming@5m@1m

→ RSI 背离，BTCUSDT.P，标题包含“Bull”，形成中，主 5 分钟，次 1 分钟

@D@ETH@Bear@confirmed@15m

→ RSI 背离，ETHUSDT.P，标题包含“Bear”，确认，15 分钟，无次时间框架

@E@BTC@Sell@30m → 额外指标，BTC 币种，标题包含“Sell”，30 分钟

@E@BTC@Buy@1h

@E@ETH@Breakout@15m

@E@BTC@Breakdown@5m

@E@BTC@Near Support@1m

@E@BTC@Near Resistance@5m

@E@BTC@EMA50@1h

@P@BTC@Up → 价格警报，BTC 币种，标题包含“Up”

@P@ETH@Down

🔀 信号组合警报

将所选来源的匹配手机通知或 webhook 消息与符合条件的 DivAlarm 信号组合，创建组合警报。关键词规则和时间窗口设置在两种模式下均有效。

设置必须在时间窗口内满足的条件以触发警报。

示例：
在 1 小时 30 分钟内：
• “关键词 A 警报”且
• “关键词 B 警报”同时到达，或
• “关键词 C 警报”到达

在 警报组合 中输入 (1&2)|3，在 时间窗口 中输入 1h 30m。

& = “且”（必须满足所有条件）

| = “或”（满足任一条件即可）

即使单个关键词警报被禁用，组合条件满足时仍可触发。

组合警报也支持自动下单！
