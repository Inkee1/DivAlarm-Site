📌 菜单概览

“DivLog” — 用于接收背离提醒信号的页面。

“Div” — 配置“RSI Divergence Complete”或“RSI Divergence Forming”信号。

“EI” — 设置额外指标提醒：价格触达提醒、接近支撑/阻力提醒、EMA/布林带/Supertrend 提醒。（“Extra Indicators”）

“Webhook” — 仅 Pro 用户可见。接收 TradingView webhook，用于强力报警、信号组合与自动下单。

“Setting” — 配置报警类型、声音、推荐奖励设置、公告与推荐通知。

📊 查看信号通知（“DivLog”）

“DivLog”是你接收背离提醒信号的地方。

  1. 最多保存 150 条信号。请定期清理。
  2. 显示未确认的提醒。勾选标记可关闭报警。最多显示最近 5 条未确认提醒。
  3. 通过筛选仅查看你想要的信号。

⚙️ RSI 背离提醒设置（“Div”）

整体 RSI 背离设置

  1. 选择要配置的币种。
  2. 在“RSI Divergence Complete”和“RSI Divergence Forming”信号之间选择。
  3. 批量设置区域 — 可一次性将设置应用到下方所有项目。
  4. 点击 + 按钮添加背离筛选条件。
  5. 将筛选条件重置为推荐默认设置。
  6. 批量设置价格条件。

单项筛选设置

  1. Configure individual RSI divergence signals to receive:

    (a) 选择所需的时间周期。对于“RSI Divergence Forming”，需同时选择“主周期”和“子周期”。当主周期背离形成（价格反转）且子周期形成 RSI 峰值时触发提醒。

    (b) 选择信号：“Bull（看涨）”或“Bear（看跌）”。蓝色=已开启提醒，灰色=已关闭。

    (c) 设置超卖/超买阈值。当“起始 RSI”低于超卖线时触发看涨提醒；当“起始 RSI”高于超买线时触发看跌提醒。

    (d) 配置报警类型与声音。详细设置请见设置页面：

    A 强制报警（循环）— 持续播放直到手动停止，忽略静音模式

    B 强制报警（一次）— 播放一次，忽略静音模式

    C 跟随手机设置 — 使用设备的常规声音设置

    D 仅震动 — 只震动不发声

    E 静音模式 — 无声音也不震动

    (e) 设置额外条件，只筛选更有用的信号：价格条件、其他周期 RSI 形成条件、布林带条件。

e0) 设置多个条件时，配置它们的关系：“and”（全部满足）或 “or”（满足任意一个）。

e1) 设置价格条件——当背离起点/终点价格高于/低于指定价格时提醒。

e2) 当其他周期正在形成背离时提醒。

e3) 检查 RSI 背离的最终峰值价格是否在布林带之外。

策略建议

  • 务必结合其他指标：压力/支撑、趋势线、斐波那契等。
  • 和所有指标一样，RSI 背离并非 100% 准确——它提升的是胜率。
  • 1m、5m 背离常被忽略，但周期越大可靠性越高：15m < 1h < 4h。4h 背离可靠性很高——建议设置为 A 级报警。

📈 额外指标提醒（“EI”）

  1. 选择要配置的币种。
  2. 为该币种设置价格提醒。
  3. 配置 EMA（指数移动平均线）交叉提醒。
  4. 设置接近支撑/压力位提醒。
  5. 配置布林带突破提醒。
  6. 设置 Supertrend 变更提醒。

※ 额外指标（3、4、5、6）在你退出登录后会重置。

🔗 TradingView Webhook、信号组合与自动下单

“Webhook”——面向高级用户的 Pro 功能。

📖 前往 Webhook 详细指南

⚙️ 设置页面

  1. 配置报警类型（A、B…）和报警声音（1、2…）。
  2. 如需自动下单，请填写各交易所的 API Key。

💰 邀请返佣

(a) 你的邀请码。其他人使用该码订阅后，你将成为其邀请人。

(b) 你的邀请链接。任何人通过该链接订阅，系统会自动将你登记为其邀请人。

(c) 填写用于领取邀请奖励的钱包地址。必须为 BEP-20 USDT 钱包（推荐使用主流交易所钱包）。你可以在 DivAlarm 网站的“我的信息”中测试充值是否正常到账。

(d) 显示你的邀请奖励状态：当前邀请人数、预计奖励金额、已确认金额、已发放金额。

在被推荐用户订阅付款（不含免费试用）后的第 14 天，奖励将从“待确认”变为“已确认”。奖励每周二 UTC 00:00 进行发放。

如何赚取推荐奖励

1] 前往 设置 → 推荐奖励 → 输入你的奖励钱包地址。

2] 分享你的推荐链接。其他人将通过你的代码跳转到订阅页面。

3] 当对方订阅并完成付款后，奖励将入账。
