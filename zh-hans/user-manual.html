📌 菜单概览

“DivLog” — 你接收背离提醒信号的地方。

“Div” — 配置“RSI 背离完成”或“RSI 背离形成中”信号。

“EI” — 设置附加指标提醒：价格触达提醒、接近支撑/阻力提醒、EMA/布林带/Supertrend 提醒。（“额外指标”）

“Webhook” — 仅对 Pro 用户可见。接收 TradingView webhooks，用于强力报警、信号组合与自动下单。

“Setting” — 配置报警类型、声音、推荐奖励设置、公告与推荐通知。

📊 查看信号通知（“DivLog”）

“DivLog”是你接收背离提醒信号的地方。

  1. 最多保存 150 条信号。请定期清理。
  2. 显示未勾选的提醒。勾选标记即可关闭报警。最多显示最近 5 条未勾选提醒。
  3. 筛选只查看你想要的信号。

🔍 查看信号详情

点击每条提醒，即可查看详细的信号信息。

对于 RSI 背离提醒，你可以看到起始与结束价格、RSI 数值以及时间戳。

“DivForming” 显示在信号触发当下，其他周期正在形成的背离。

“OutsideBB” 显示信号触发时，哪些周期处于布林带之外。

  • 对于比信号周期更小的周期，它会显示在信号触发当下（at now）哪些 K 线在布林带之外。
  • 对于比信号周期更大的周期，它会显示在之后的 RSI 背离峰值（at peak）时哪些 K 线在布林带之外。

  • 在 RSI 背离峰值处，15m、30m 和 1h 周期位于布林带之外。

⚙️ RSI 背离提醒设置（“Div”）

整体 RSI 背离设置

  1. 选择要配置的币种。
  2. 在“RSI 背离完成”和“RSI 背离形成中”信号之间选择。
  3. 批量设置区域——一次性将设置应用到下方所有项目。
  4. 点击 + 按钮添加背离过滤条件。
  5. 将过滤条件重置为推荐的默认设置。
  6. 批量设置价格条件。

单个过滤条件设置

  1. Configure individual RSI divergence signals to receive:

    (a) 选择所需周期。对于“RSI 背离形成中”，需同时选择“主周期”和“子周期”。当主周期背离正在形成（价格反转）且小周期形成 RSI 峰值时触发提醒。

    (b) 选择信号：“Bull（看涨）”或“Bear（看跌）”。蓝色=已开启提醒，灰色=已关闭。

    (c) 设置超卖/超买阈值。当“起始 RSI”低于超卖线时触发看涨提醒；当“起始 RSI”高于超买线时触发看跌提醒。

    (d) 配置闹钟类型与声音。详细设置在设置页面：

    A 强制闹钟（循环）——持续播放直到手动停止，忽略静音模式

    B 强制闹钟（一次）——播放一次，忽略静音模式

    C 跟随手机设置——使用设备的常规声音设置

    D 仅震动——只震动不响铃

    E 静音模式——无声音也不震动

    (e) 仅为更有用的信号设置附加条件：价格条件、其他周期 RSI 形成条件、布林带条件。

e0) 当设置了多个条件时，配置它们的关系：“and”（全部满足）或“or”（满足任意一个）。

e1) 设置价格条件——当背离起点/终点价格高于或低于指定价格时提醒。

e2) 当另一个周期正在形成背离时提醒。

e3) 检查 RSI 背离最终峰值价格是否在布林带之外。

策略建议

  • 务必结合其他指标使用：阻力位、趋势线、斐波那契等。
  • 和所有指标一样，RSI 背离并非 100% 准确——它只是提高胜率。
  • 1m、5m 的背离常被忽略，但周期越大可靠性越高：15m < 1h < 4h。4h 背离可靠性很高——建议设为 A 级警报。

📈 额外指标警报（“EI”）

  1. 选择要配置的币种。
  2. 为该币种设置价格警报。
  3. 配置 EMA（指数移动平均线）交叉警报。
  4. 设置接近支撑/阻力位警报。
  5. 配置布林带突破警报。
  6. 设置 Supertrend 变更警报。

※ 额外指标（3、4、5、6）在你退出登录时会重置。

🔗 TradingView Webhook、信号组合与自动下单

“Webhook”——面向高级用户的 Pro 功能。

📖 前往 Webhook 详细指南

⚙️ 设置页面

  1. 配置警报类型（A、B…）和警报声音（1、2…）。
  2. 如需自动下单，请输入各交易所的 API Key。
  3. 你可以测试通知是否能送达当前手机。通过给自己发送测试消息，可检查警报是否会按你配置的筛选条件正常推送。
  4. 用于设置推荐奖励相关选项的页面。
  5. 在这里接收全站公告。
  6. 在这里接收你注册时填写的推荐人发送的专属公告。
  7. 可在浅色模式与深色模式之间切换整个应用。

💰 推荐奖励

(a) 你的推荐码。其他人使用此码订阅后，你将成为其推荐人。

(b) 你的邀请链接。任何人通过该链接订阅，都会自动将你登记为其推荐人。

(c) 输入用于接收推荐奖励的钱包地址。必须是 BEP-20 USDT 钱包（建议使用主流交易所钱包）。你可以在 DivAlarm 网站的“我的信息”中测试充值是否正常。

(d) 显示你的推荐奖励状态：当前推荐人数、预计奖励金额、已确认金额和已支付金额。

被推荐用户完成订阅付款（不含免费试用）后 14 天，奖励将从“预计”转为“已确认”。付款每周二在 UTC 0 点进行。

如何获得推荐奖励

1] 前往 设置 → 推荐奖励 → 输入你的奖励钱包地址。

2] 分享你的推荐链接。其他人将通过你的代码跳转到订阅页面。

3] 对方订阅并付款后，奖励将自动入账。
