🔔 키워드 알림

TradingView에 웹훅 추가하기

TradingView에서 신호를 받고 싶은 지표를 오른쪽 클릭하고 "~에 알림 추가"를 클릭하세요.

"알림" 섹션에서 "웹훅 URL"을 체크하고, 아래 입력란에 앱에서 복사한 주소를 붙여넣으세요.

설정 후, 다른 알림에도 자동으로 체크/입력됩니다.

"메시지" 섹션에서 "메시지" 아래에 원하는 키워드(예: "AAA")를 추가하세요.

"생성"을 클릭하여 TradingView 알림을 예약하세요.

앱에서 TradingView 알림 받기

앱의 '키워드 포함' 섹션에 키워드(예: "AAA")를 추가하세요. TradingView 알림 "메시지"에 키워드가 포함되면 설정된 대로 알람이 울립니다.

🤖 TradingView 알림으로 자동 주문

키워드 알림을 받을 때 거래소로 '자동 주문'을 보낼 수 있습니다.

자동 주문을 지원하는 거래소: Binance, ByBit, OKX, Bitget, Gate

앱 설정 페이지에 API 키를 입력해야 합니다.

📝 DivAlarm 신호를 키워드로 등록하기

DivAlarm의 자체 알림도 '키워드 조합'에 추가할 수 있습니다 (조합 알림 또는 자동 주문용).

형식: @알람유형@코인명접두사@제목키워드@시간프레임@두번째시간프레임(있을 경우)

알람 유형:

  • @D — RSI 다이버전스 필터
  • @E — 추가 지표
  • @P — 가격 알림

예시

"@D@BTC@Bull@5m@1m"

→ RSI 다이버전스, BTCUSDT.P, 제목에 "Bull" 포함, 형성 중, 메인 5분, 서브 1분

"@D@ETH@Bear@15m@O"

→ RSI 다이버전스, ETHUSDT.P, 제목에 "Bear" 포함, 완료, 15분, 서브 시간 없음

"@E@BTC@Sell@30m" → 추가 지표, BTC 코인, 제목에 "Sell" 포함, 30분

"@E@BTC@Buy@1h"

"@E@ETH@Breakout@15m"

"@E@BTC@Breakdown@5m"

"@E@BTC@Near Support@1m"

"@E@BTC@Near Resistance@5m"

"@E@BTC@EMA50@1h"

"@P@BTC@Up" → 가격 알림, BTC 코인, 제목에 "Up" 포함

"@P@ETH@Down"

🔀 신호 조합 알림

여러 TradingView 신호를 조합하여 새로운 신호나 필터링된 신호를 만드세요.

알람이 작동하기 위해 시간 내에 충족해야 하는 조건을 설정하세요.

예시:
1시간 30분 이내:
• '키워드 A 알림' 그리고
• '키워드 B 알림' 둘 다 도착하거나,
• '키워드 C 알림' 도착

입력 (1&2)|3 '알람 조합'에 1h 30m '시간 조합'에

& = "AND" (두 조건 모두 충족)

| = "OR" (어느 한 조건 충족)

개별 키워드 알람이 비활성화되어도, 조건이 충족되면 조합이 작동할 수 있습니다.

조합 알림으로 자동 주문도 가능합니다!
