📌 메뉴 개요

"DivLog" — 다이버전스 알림 신호를 받는 곳입니다.

"Div" — 'RSI 다이버전스 완료' 또는 'RSI 다이버전스 형성 중' 신호를 설정하세요.

"EI" — 추가 지표 알림 설정: 가격 도달 알림, 지지/저항 접근 알림, EMA/볼린저 밴드/슈퍼트렌드 알림. ("추가 지표")

"Webhook" — Pro 사용자에게만 보입니다. 강력한 알람, 신호 조합, 자동 주문을 위한 TradingView 웹훅을 받으세요.

"설정" — 알람 유형, 소리, 추천 보상 설정, 공지사항 및 추천 알림을 설정하세요.

📊 신호 알림 보기 ("DivLog")

"DivLog"는 다이버전스 알림 신호를 받는 곳입니다.

  1. 최대 150개의 신호가 저장됩니다. 주기적으로 정리하세요.
  2. 확인되지 않은 알림을 표시합니다. 알람을 해제하려면 체크 표시를 하세요. 최대 5개의 최근 미확인 알림이 표시됩니다.
  3. 원하는 신호만 보이도록 필터링하세요.

⚙️ RSI 다이버전스 알림 설정 ("Div")

전체 RSI 다이버전스 설정

  1. 설정할 코인을 선택하세요.
  2. 'RSI 다이버전스 완료'와 'RSI 다이버전스 형성 중' 신호 중에서 선택하세요.
  3. 일괄 설정 영역 — 아래 모든 항목에 설정을 한 번에 적용합니다.
  4. + 버튼으로 다이버전스 필터를 추가하세요.
  5. 필터를 권장 기본 설정으로 재설정하세요.
  6. 가격 조건을 일괄 설정하세요.

개별 필터 설정

  1. 개별 RSI 다이버전스 신호를 설정하여 받으세요:

    (a) 원하는 시간대를 선택하세요. 'RSI 다이버전스 형성 중'의 경우 '주 시간대'와 '보조 시간대'를 모두 선택하세요. 작은 시간대에서 RSI 피크가 형성되면서 주 시간대에서 다이버전스가 형성될 때 알림이 발생합니다 (가격 반전).

    (b) 신호를 선택하세요: "Bull(상승)" 또는 "Bear(하락)". 파란색 = 알림 활성화, 회색 = 비활성화.

    (c) 과매도/과매수 임계값을 설정하세요. '시작 RSI'이 과매도 수준 아래에 있을 때는 매수 알림, '시작 RSI'이 과매수 수준 위에 있을 때는 매도 알림이 발생합니다.

    (d) 알람 유형과 소리를 설정하세요. 자세한 설정은 설정 페이지에서 확인하세요:

    A 강제 알람 (반복) — 수동으로 중지할 때까지 계속 재생, 무음 모드 무시

    B 강제 알람 (한 번) — 한 번 재생, 무음 모드 무시

    C 휴대폰 설정 따름 — 기기의 일반 소리 설정 사용

    D 진동만 — 소리 없이 진동

    E 무음 모드 — 소리 및 진동 없음

    (e) 유용한 신호를 위한 추가 조건 설정: 가격 조건, 다른 시간대 RSI 형성 조건, 볼린저 밴드 조건.

e0) 여러 조건이 설정된 경우 관계를 구성하세요: "그리고" (모두 만족해야 함) 또는 "또는" (하나만 만족해도 됨).

e1) 가격 조건 설정 — 발산 시작/종료 가격이 특정 가격 이상/이하일 때 알림.

e2) 다른 시간대에서 발산이 형성될 때 알림.

e3) RSI 발산의 최종 피크 가격이 볼린저 밴드 밖에 있는지 확인하세요.

전략 팁

  • 항상 다른 지표와 결합하세요: 저항선, 추세선, 피보나치 등.
  • 모든 지표와 마찬가지로 RSI 발산은 100% 정확하지 않으며, 확률을 높여줍니다.
  • 1분, 5분 발산은 종종 무시되지만, 신뢰성은 증가합니다: 15분 < 1시간 < 4시간. 4시간 발산은 매우 신뢰할 수 있습니다 — A급 알람으로 설정하는 것을 권장합니다.

📈 추가 지표 알림 ("EI")

  1. 설정할 코인을 선택하세요.
  2. 코인의 가격 알림을 설정하세요.
  3. EMA (지수 이동 평균) 교차 알림을 설정하세요.
  4. 지지/저항 접근 알림을 설정하세요.
  5. 볼린저 밴드 돌파 알림을 설정하세요.
  6. 슈퍼트렌드 변화 알림을 설정하세요.

※ 추가 지표 (3, 4, 5, 6)는 로그아웃 시 초기화됩니다.

💰 추천 보상

(a) 귀하의 추천 코드입니다. 다른 사용자가 이 코드를 사용하여 구독하면 귀하가 추천인이 됩니다.

(b) 귀하의 초대 링크입니다. 이 링크를 통해 구독한 사람은 자동으로 귀하를 추천인으로 등록합니다.

(c) 추천 보상을 위한 지갑 주소를 입력하세요. 반드시 BEP-20 USDT 지갑이어야 합니다 (주요 거래소 지갑 권장). DivAlarm 웹사이트의 '내 정보'에서 입금이 정상적으로 이루어지는지 테스트할 수 있습니다.

(d) 추천 보상 상태를 보여줍니다: 현재 추천 수, 예상 보상 금액, 확정 금액, 지급 금액.

보상은 추천 사용자의 구독 결제 후 14일 후에 '예상'에서 '확정'으로 이동합니다 (무료 체험 제외). 지급은 매주 화요일 UTC 자정에 이루어집니다.

추천 보상 받는 방법

1] 설정 → 추천 보상 → 보상 지갑 주소 입력으로 이동하세요.

2] 추천 링크를 공유하세요. 다른 사용자는 귀하의 코드로 구독 페이지로 이동합니다.

3] 그들이 구독하고 결제하면 보상이 입금됩니다.
