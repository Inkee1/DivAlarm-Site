📌 메뉴 개요

"DivLog" — 다이버전스 알림 시그널을 받는 곳입니다.

"Div" — ‘RSI Divergence Complete’ 또는 ‘RSI Divergence Forming’ 시그널을 설정합니다.

"EI" — 추가 인디케이터 알림을 설정합니다: 가격 도달 알림, 지지·저항 근접 알림, EMA/Bollinger Band/Supertrend 알림. ("Extra Indicators")

"Webhook" — Pro 사용자에게만 표시됩니다. 강력한 알람, 시그널 조합, 자동 주문을 위해 TradingView 웹훅을 수신합니다.

"설정" — 알림 유형, 사운드, 추천인 리워드 설정, 공지사항, 추천인 알림을 설정합니다.

📊 시그널 알림 확인("DivLog")

"DivLog"는 다이버전스 알림 시그널을 받는 곳입니다.

  1. 최대 150개의 시그널이 저장됩니다. 주기적으로 정리하세요.
  2. 미확인 알림을 표시합니다. 체크 표시를 눌러 알람을 해제하세요. 최근 미확인 알림은 최대 5개까지 표시됩니다.
  3. 원하는 시그널만 보이도록 필터링합니다.

🔍 시그널 상세 보기

각 알림을 탭하면 시그널의 상세 정보를 확인할 수 있습니다.

RSI 다이버전스 알림에서는 시작/종료 가격, RSI 값, 타임스탬프를 확인할 수 있습니다.

"DivForming"은 시그널 발생 시점에 다른 타임프레임에서 형성 중인 다이버전스를 보여줍니다.

"OutsideBB"는 시그널 발생 시점에 어떤 타임프레임이 볼린저 밴드 밖에 있었는지 보여줍니다.

  • 시그널 타임프레임보다 작은 타임프레임은 시그널 시점(현재)에 어떤 캔들이 볼린저 밴드 밖이었는지 보여줍니다.
  • 시그널 타임프레임보다 큰 타임프레임은 이후 RSI 다이버전스 피크 시점(피크)에 어떤 캔들이 볼린저 밴드 밖이었는지 보여줍니다.

예시

위 예시에서는 15m 타임프레임에서 상승 시그널이 발생합니다.

"DivForming"은 30m와 1h 타임프레임에서 하락 다이버전스가 형성 중임을 나타냅니다.

"OutsideBB"는 다음을 보여줍니다:

  • 시그널 시점에 5m 타임프레임이 볼린저 밴드 밖이었습니다.
  • RSI 다이버전스 피크 시점에는 15m, 30m, 1h 타임프레임이 볼린저 밴드 밖이었습니다.

⚙️ RSI 다이버전스 알림 설정("Div")

전체 RSI 다이버전스 설정

  1. 설정할 코인을 선택합니다.
  2. 'RSI 다이버전스 완료'와 'RSI 다이버전스 형성 중' 시그널 중에서 선택합니다.
  3. 일괄 설정 영역 — 아래 항목 전체에 설정을 한 번에 적용합니다.
  4. + 버튼으로 다이버전스 필터를 추가합니다.
  5. 필터를 권장 기본값으로 초기화합니다.
  6. 가격 조건을 일괄로 설정합니다.

개별 필터 설정

  1. Configure individual RSI divergence signals to receive:

    (a) 원하는 타임프레임을 선택합니다. 'RSI 다이버전스 형성 중'의 경우 '메인 타임프레임'과 '서브 타임프레임'을 모두 선택하세요. 메인 타임프레임에서 다이버전스가 형성되는 동안, 더 작은 타임프레임에서 RSI 피크가 형성되면(가격 반전) 알림이 발생합니다.

    (b) 시그널을 선택합니다: "Bull(상승)" 또는 "Bear(하락)". 파란색 = 알림 켜짐, 회색 = 꺼짐.

    (c) 과매도/과매수 기준값을 설정하세요. 'starting RSI'가 과매도 기준 아래면 강세 알림, 'starting RSI'가 과매수 기준 위면 약세 알림이 울립니다.

    (d) 알람 유형과 소리를 설정하세요. 자세한 설정은 설정 페이지에서 할 수 있습니다:

    A 강제 알람(반복) — 수동으로 멈출 때까지 계속 재생되며, 무음 모드를 무시합니다

    B 강제 알람(1회) — 1회 재생되며, 무음 모드를 무시합니다

    C 휴대폰 설정 따름 — 기기의 기본 소리 설정을 사용합니다

    D 진동만 — 소리 없이 진동만 울립니다

    E 무음 모드 — 소리/진동 없음

    (e) 유용한 신호만 받도록 추가 조건을 설정하세요: 가격 조건, 다른 타임프레임 RSI 형성 조건, 볼린저 밴드 조건.

e0) 조건을 여러 개 설정했다면 관계를 선택하세요: "and"(모두 충족) 또는 "or"(하나만 충족).

e1) 가격 조건 설정 — 다이버전스 시작/종료 가격이 특정 가격보다 위/아래일 때 알림을 울립니다.

e2) 다른 타임프레임에서 다이버전스가 형성 중일 때 알림을 울립니다.

e3) RSI 다이버전스의 마지막 고점 가격이 볼린저 밴드 밖인지 확인합니다.

전략 팁

  • 항상 다른 지표와 함께 보세요: 저항, 추세선, 피보나치 등.
  • 모든 지표가 그렇듯 RSI 다이버전스도 100% 정확하진 않습니다 — 확률을 높여줍니다.
  • 1m, 5m 다이버전스는 자주 무시되지만, 신뢰도는 15m < 1h < 4h 순으로 높아집니다. 4h 다이버전스는 신뢰도가 매우 높으니 A급 알람으로 설정하는 것을 권장합니다.

📈 추가 지표 알림("EI")

  1. 설정할 코인을 선택합니다.
  2. 코인 가격 알림을 설정하세요.
  3. EMA(Exponential Moving Average) 교차 알림을 설정하세요.
  4. 지지·저항 접근 알림을 설정하세요.
  5. 볼린저 밴드 돌파 알림을 설정하세요.
  6. 슈퍼트렌드 전환 알림을 설정하세요.

※ 추가 지표(3, 4, 5, 6)는 로그아웃하면 초기화됩니다.
