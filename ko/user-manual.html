📌 메뉴 한눈에 보기

"DivLog" — 다이버전스 알림 신호를 받는 곳입니다.

"Div" — 'RSI Divergence Complete' 또는 'RSI Divergence Forming' 신호를 설정합니다.

"EI" — 추가 지표 알림을 설정합니다: 가격 도달 알림, 지지·저항 접근 알림, EMA/Bollinger Band/Supertrend 알림. ("Extra Indicators")

"Webhook" — Pro 사용자에게만 표시됩니다. 강력한 알람, 신호 조합, 자동 주문을 위해 TradingView 웹훅을 받습니다.

"Setting" — 알람 유형, 사운드, 추천인 리워드 설정, 공지사항, 추천인 알림을 설정합니다.

📊 신호 알림 확인하기 ("DivLog")

"DivLog"는 다이버전스 알림 신호를 받는 곳입니다.

  1. 최대 150개의 신호가 저장됩니다. 주기적으로 정리하세요.
  2. 확인하지 않은 알림을 표시합니다. 체크 표시를 누르면 알람이 해제됩니다. 최근 미확인 알림은 최대 5개까지 표시됩니다.
  3. 원하는 신호만 보이도록 필터링하세요.

⚙️ RSI 다이버전스 알림 설정 ("Div")

전체 RSI 다이버전스 설정

  1. 설정할 코인을 선택하세요.
  2. 'RSI Divergence Complete'와 'RSI Divergence Forming' 신호 중에서 선택하세요.
  3. 일괄 설정 영역 — 아래 항목 전체에 한 번에 적용합니다.
  4. + 버튼으로 다이버전스 필터를 추가하세요.
  5. 필터를 권장 기본값으로 초기화합니다.
  6. 가격 조건을 일괄로 설정합니다.

개별 필터 설정

  1. Configure individual RSI divergence signals to receive:

    (a) 원하는 타임프레임을 선택하세요. 'RSI Divergence Forming'의 경우 '메인 타임프레임'과 '서브 타임프레임'을 모두 선택합니다. 메인 타임프레임에서 다이버전스가 형성되는 동안(가격 반전) 더 작은 타임프레임에서 RSI 피크가 형성되면 알림이 울립니다.

    (b) 신호를 선택하세요: "Bull(상승)" 또는 "Bear(하락)". 파란색 = 알림 켜짐, 회색 = 꺼짐.

    (c) 과매도/과매수 기준값을 설정하세요. '시작 RSI'가 과매도 기준 아래면 상승 알림, '시작 RSI'가 과매수 기준 위면 하락 알림이 울립니다.

    (d) 알람 유형과 사운드를 설정하세요. 자세한 설정은 설정 페이지에서 확인할 수 있습니다:

    A 강제 알람(반복) — 수동으로 멈출 때까지 계속 재생되며, 무음 모드를 무시합니다

    B 강제 알람(1회) — 1회 재생되며, 무음 모드를 무시합니다

    C 휴대폰 설정 따름 — 기기의 일반 사운드 설정을 사용합니다

    D 진동만 — 소리 없이 진동만 울립니다

    E 무음 모드 — 소리와 진동이 모두 없습니다

    (e) 유용한 신호만 받도록 추가 조건을 설정하세요: 가격 조건, 다른 타임프레임 RSI 형성 조건, 볼린저 밴드 조건.

e0) 여러 조건을 설정한 경우, 조건 간 관계를 설정하세요: "and"(모두 충족) 또는 "or"(하나만 충족).

e1) 가격 조건 설정 — 다이버전스 시작/종료 가격이 특정 가격 위/아래일 때 알림을 받습니다.

e2) 다른 타임프레임에서 다이버전스가 형성 중일 때 알림을 받습니다.

e3) RSI 다이버전스의 최종 고점 가격이 볼린저 밴드 밖인지 확인합니다.

전략 팁

  • 항상 다른 지표와 함께 보세요: 저항선, 추세선, 피보나치 등.
  • 모든 지표가 그렇듯 RSI 다이버전스도 100% 정확하진 않습니다 — 확률을 높여줍니다.
  • 1m, 5m 다이버전스는 자주 무시되지만, 신뢰도는 15m < 1h < 4h로 올라갑니다. 4h 다이버전스는 신뢰도가 매우 높으니 A등급 알람으로 설정하는 것을 추천합니다.

📈 추가 지표 알림("EI")

  1. 설정할 코인을 선택하세요.
  2. 해당 코인의 가격 알림을 설정합니다.
  3. EMA(Exponential Moving Average) 교차 알림을 설정합니다.
  4. 지지·저항 접근 알림을 설정합니다.
  5. 볼린저 밴드 돌파 알림을 설정합니다.
  6. 슈퍼트렌드 전환 알림을 설정합니다.

※ 추가 지표(3, 4, 5, 6)는 로그아웃하면 초기화됩니다.

💰 추천인 리워드

(a) 내 추천인 코드입니다. 다른 사람이 이 코드로 구독하면, 내가 해당 사용자의 추천인이 됩니다.

(b) 내 초대 링크입니다. 이 링크로 구독한 사람은 자동으로 나를 추천인으로 등록합니다.

(c) 추천인 리워드를 받을 지갑 주소를 입력하세요. BEP-20 USDT 지갑이어야 합니다(주요 거래소 지갑 권장). 입금이 정상적으로 되는지는 DivAlarm 웹사이트의 '내 정보'에서 테스트할 수 있습니다.

(d) 추천인 리워드 현황을 표시합니다: 현재 추천인 수, 예상 리워드 금액, 확정 금액, 지급 완료 금액.

추천받은 사용자의 구독 결제(무료 체험 제외) 후 14일이 지나면 리워드가 '예정'에서 '확정'으로 전환됩니다. 지급은 매주 화요일 UTC 00:00에 진행됩니다.

추천 리워드 받는 방법

1] 설정 → 추천 리워드 → 리워드 지갑 주소를 입력하세요.

2] 추천 링크를 공유하세요. 다른 사용자는 내 코드가 적용된 구독 페이지로 이동합니다.

3] 상대가 구독하고 결제하면 리워드가 입금됩니다.
