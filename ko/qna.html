자주 묻는 질문

DivAlarm에 대한 일반적인 질문에 대한 답변을 찾아보세요.

🔍
기술적
RSI 값이 TradingView 또는 다른 플랫폼과 약간 다른 이유는 무엇인가요?

RSI 값은 평균을 사용합니다. 14 캔들그리고 계산의 시작점이 값의 약간의 차이를 유발할 수 있습니다.

또한, 두 가지 주요 계산 방법이 있습니다: EMA (지수 이동 평균) 그리고 SMA (단순 이동 평균).

DivAlarm는 RSI을 계산하는 방식입니다. 최근 추세를 더 잘 반영합니다다른 플랫폼과 비교했을 때 약간의 차이가 있을 수 있습니다.

계정
계정당 한 명만 앱을 사용할 수 있나요?

네신호는 주로 가장 최근에 로그인한 기기로 전송됩니다.

동시에 여러 기기에 로그인한 경우 일부 신호가 여러 기기로 수신될 수 있지만, 안정적인 작동을 위해 마지막으로 로그인한.

문제가 발생하면 설정 → 동기화 설정 으로 이동하여 "이 기기로 수신"을 탭하세요 정상적인 기능을 보장하기 위해.

플랫폼
iPhone(iOS) 버전이 있나요?

Apple의 iOS는 훨씬 더 엄격한 정책을 가지고 있습니다 Android와 비교했을 때.

주요 제한 사항은 다음과 같습니다:

• 강제 알람 이 무음 모드를 무시하는 것은 허용되지 않습니다
• 백그라운드 자동 주문 이 제한됩니다
• 푸시 알림 전달이 더 제한적입니다

우리는 기능이 제한된 버전 을 iOS용으로 출시할 수 있지만, 아직 확정된 일정은 없습니다.

기능
DivForming에서 "1m/1m"은 무엇을 의미하나요?

그 1분/1분 설정이 알림을 발생시킵니다 순간 1분 차트에서 다이버전스가 형성되려 할 때.

이는 언제든지 알림을 받을 수 있다는 의미입니다 캔들 추세와 RSI 추세가 다이버전스 시작 — 가능한 한 빨리 잠재적 반전을 포착합니다.

이는 알림을 받고자 하는 트레이더에게 이상적입니다 확인되기 전 다이버전스가 완전히 확인되기 전에.

기술적
RSI 다이버전스란 무엇이며 왜 중요한가요?

RSI 다이버전스 가격 움직임과 RSI 지표가 반대 방향으로 움직일 때 발생합니다.

강세 다이버전스: 가격이 더 낮은 저점을 만들지만 RSI는 더 높은 저점을 만듭니다 → 잠재적 상승 반전

약세 다이버전스: 가격이 더 높은 고점을 만들지만 RSI는 더 낮은 고점을 만듭니다 → 잠재적 하락 반전

RSI 다이버전스는 널리 인정받고 있습니다 가장 신뢰할 수 있는 지표 중 하나 기술 분석에서 시장 반전을 예측하기 위해.

기능
TradingView 웹훅 통합은 어떻게 작동하나요?

함께 프로 구독, 고유한 웹훅 URL을 받아 DivAlarm와 TradingView를 연결합니다.

기능에는 다음이 포함됩니다:

• 강력한 전화 알람 무음 모드를 우회하는
• 복합 신호 — 여러 알림을 하나로 결합
• 자동 주문 실행 지원되는 거래소에서

간단히 TradingView의 알림 설정에 웹훅 URL을 붙여넣고, 알림 메시지에 특정 키워드를 포함시켜 해당 작업을 트리거하세요.

기능
자동 주문은 어떻게 작동하나요?

자동 주문 (프로 전용) 선택한 TradingView 알림이 발생하면 자동으로 거래를 실행합니다.

최대 지원 5개 거래소을(를) 지원하며, 다음을 수행할 수 있습니다:

• 특정 알림 키워드로 매수/매도 주문 설정
• 주문 크기, 유형 및 조건 구성
• 휴대폰이 주머니에 있어도 거래 실행

참고: 자동 주문은 거래소와의 올바른 API 키 설정이 필요합니다.

😕 검색어와 일치하는 질문이 없습니다.

다른 키워드를 시도하거나 문의하기 도움을 받으세요.
