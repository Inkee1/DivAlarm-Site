자주 묻는 질문

DivAlarm에 대한 자주 묻는 질문의 답을 확인하세요

🔍
기술
왜 RSI 값이 TradingView 또는 다른 플랫폼과 약간 다른가요?

RSI 값은 14개 캔들의 평균을 사용하며, 계산 시작 지점에 따라 값이 약간 달라질 수 있습니다.

또한 대표적인 계산 방식은 두 가지가 있습니다: EMA (Exponential Moving Average)와 SMA (Simple Moving Average)입니다.

DivAlarm는 최근 추세를 더 잘 반영하도록 RSI를 계산하기 때문에, 다른 플랫폼과 비교했을 때 미세한 차이가 날 수 있습니다.

계정
계정당 한 사람만 앱을 사용할 수 있나요?

네, 신호는 기본적으로 가장 최근에 로그인한 기기로 전송됩니다.

동시에 로그인되어 있으면 일부 신호가 여러 기기에서 수신될 수도 있지만, 안정적인 사용을 위해 마지막으로 로그인한 기기에서 사용하시는 것을 권장합니다.

문제가 발생하면 앱에서 설정 → 동기화 설정으로 이동한 뒤 "이 기기에서 받기"를 탭해 정상 동작을 확인해 주세요.

플랫폼
아이폰(iOS) 버전이 있나요?

Apple의 iOS는 Android에 비해 정책이 훨씬 더 엄격합니다.

주요 제한 사항은 다음과 같습니다:

• 무음 모드를 무시하는 강제 알람은 허용되지 않습니다
• 백그라운드 자동 주문은 제한됩니다
• 푸시 알림 전달이 더 제한적입니다

향후 iOS용 기능 제한 버전을 출시할 수도 있지만, 아직 확정된 일정은 없습니다.

기능
DivForming에서 "1m/1m"은 무슨 뜻인가요?

1m/1m 설정은 1분 차트에서 다이버전스가 형성되기 직전 순간에 알림을 울립니다.

즉, 캔들 추세와 RSI 추세가 벌어지기 시작할 때마다 알림을 받아, 가능한 한 가장 이른 시점에 잠재적 반전을 포착할 수 있습니다.

다이버전스가 완전히 확정되기 전에 알림을 받고 싶은 트레이더에게 적합합니다.

기술
RSI 다이버전스란 무엇이며, 왜 중요한가요?

RSI 다이버전스는 가격 움직임과 RSI 지표가 서로 반대 방향으로 움직일 때 발생합니다.

강세 다이버전스: 가격은 저점을 낮추지만, RSI는 저점을 높입니다 → 상승 반전 가능성

약세 다이버전스: 가격은 고점을 높이지만, RSI는 고점을 낮춥니다 → 하락 반전 가능성

RSI 다이버전스는 기술적 분석에서 시장 반전을 예측하는 가장 신뢰도 높은 지표 중 하나로 널리 알려져 있습니다.

기능
TradingView 웹훅 연동은 어떻게 작동하나요?

Pro 구독을 이용하면 DivAlarm와 TradingView을(를) 연결하는 고유한 웹훅 URL을 받습니다.

기능은 다음과 같습니다:

• 무음 모드를 무시하는 강력한 휴대폰 알람
• 복합 신호 — 여러 알림을 하나로 결합
• 지원 거래소에서 자동 주문 실행

TradingView의 알림 설정에 웹훅 URL을 붙여넣고, 알림 메시지에 지정된 키워드를 포함하면 해당 동작이 실행됩니다.

기능
자동 주문은 어떻게 작동하나요?

자동 주문(Pro 전용)은 선택한 TradingView 알림이 발생하면 거래를 자동으로 실행합니다.

최대 5개 거래소를 지원하며, 다음을 할 수 있습니다:

• 특정 알림 키워드로 매수/매도 주문 트리거 설정
• 주문 수량, 유형, 조건 설정
• 휴대폰이 주머니에 있어도 거래 실행

참고: 자동 주문을 사용하려면 거래소에서 API 키를 올바르게 설정해야 합니다.
